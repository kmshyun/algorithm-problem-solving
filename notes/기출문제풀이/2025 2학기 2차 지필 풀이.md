# [1-3] 예산 상한선 H 정하기

상한선 H를 넘는 부서는 초과분만큼 삭감. 총 삭감액 ≥ M이면서 H를 최대한 높게.

## 1번 (5점)

### 1-1) 표 ([120, 110, 140, 150])

| H | 부서별 삭감 | 총 삭감 |
|---|-------------|---------|
| 100 | 20, 10, 40, 50 | 120 |
| 120 | 0, 0, 20, 30 | 50 |
| 150 | 0, 0, 0, 0 | 0 |

### 1-2) H가 커질수록 총 삭감액은 단조 감소 → 이분 탐색 (O(N log V))

## 2번. 완전 탐색 (7점)

```py
def solution(target_cut, budgets):
    max_budget = max(budgets)
    for baseline in range(max_budget, -1, -1):
        current_cut = sum(budget - baseline for budget in budgets if budget > baseline)
        if current_cut >= target_cut:
            return baseline
```

- 2-1) baseline = 상한선 H 후보
- 2-2) 큰 값부터 내려오면 처음 만족하는 게 최댓값 → 바로 return
- 2-3) 0부터 키우면? **아니다**. 작은 H는 전부 만족해서 0에서 멈춤 (최소가 아니라 목표와 반대)
- 2-4) O(N × V) — V 크면 불가 → 이분 탐색 필요

## 3번. 이분 탐색 (18점)

```py
def solution(target_cut, budgets):
    low = 0
    high = max(budgets)
    answer = 0
    while low <= high:
        mid = (low + high) // 2
        cut = sum(budget - mid for budget in budgets if budget > mid)
        if cut >= target_cut:      # 충분 → 후보 저장, H 키움
            answer = mid
            low = mid + 1
        else:                      # 모자람 → H 낮춤
            high = mid - 1
    return answer
```

- 패턴: 만족하면 `answer = mid` 후 `low = mid + 1`. O(N log V)

# [4-6] N을 1로 만드는 최소 연산 횟수

연산: ÷3(가능하면), ÷2(가능하면), −1.

## 4번. 그리디 (6점)

```py
def solution(n):
    count = 0
    while n > 1:
        if n % 3 == 0:
            n //= 3
        elif n % 2 == 0:
            n //= 2
        else:
            n -= 1
        count += 1
    return count
```

- 4-1) solution(9)=2, solution(10)=4
- 4-2) ② 최적 보장 못 함. 반례 N=10: 그리디 4번(10→5→4→2→1), 최적 3번(10→9→3→1)

## 5번. 재귀 (8점)

```py
def solution(n):
    if n == 1:
        return 0
    result = solution(n - 1) + 1
    if n % 2 == 0:
        result = min(result, solution(n // 2) + 1)
    if n % 3 == 0:
        result = min(result, solution(n // 3) + 1)
    return result
```

- 5-1) **최적해 찾음** (모든 경로 비교). `f(n) = min(f(n-1), f(n/2), f(n/3)) + 1`
- 5-2) O(3ᴺ), 중복 부분 문제 반복 계산 → 메모이제이션/DP로 O(N)

## 6번. O(N) DP (16점)

```py
def solution(n):
    dp = [0] * (n + 1)          # dp[1] = 0
    for i in range(2, n + 1):
        dp[i] = dp[i - 1] + 1
        if i % 2 == 0:
            dp[i] = min(dp[i], dp[i // 2] + 1)
        if i % 3 == 0:
            dp[i] = min(dp[i], dp[i // 3] + 1)
    return dp[n]
```

- dp[1..10] = 0,1,1,2,3,2,3,3,2,3. solution(9)=2, solution(10)=3

# [7-10] 비트로 표현한 미로 + BFS

각 칸의 벽 = 1(왼),2(위),4(오른),8(아래)의 합.

## 7번. 벽 정보 (10점)

- 7-1) 1=0001 왼, 2=0010 위, 4=0100 오른, 8=1000 아래. 자리가 안 겹쳐 조합이 유일
- 7-2) 1,2,3,4를 쓰면? 합이 겹침 (3 = 오른쪽만? 1+2? 구분 불가). 비트로 방향 하나만 꺼낼 수도 없음
- 7-3) 0 = 4방향 모두 / 13 = 1101 = 8+4+1 → 위쪽만

## 8번. BFS 코드 (9점)

```py
wall_bit = [1, 2, 4, 8]
dx = [0, -1, 0, 1]
dy = [-1, 0, 1, 0]

def bfs(maze, sx, sy):
    visited = [[False] * M for _ in range(N)]
    parent = [[None] * M for _ in range(N)]
    queue = deque([(sx, sy, 0)])
    visited[sx][sy] = True
    while queue:
        x, y, dist = queue.popleft()
        if x == N-1 and y == M-1:
            path = reconstruct_path(parent, x, y)
            return dist, path
        for i in range(4):
            if maze[x][y] & wall_bit[i]:      # i 방향에 벽 있으면
                continue
            nx, ny = x + dx[i], y + dy[i]
            if 0 <= nx < N and 0 <= ny < M and not visited[nx][ny]:
                queue.append((nx, ny, dist + 1))
                visited[nx][ny] = True
                parent[nx][ny] = (x, y)
    return -1, []
```

- 8-1) `maze[x][y] & wall_bit[i]`: 비트 AND. 그 방향 벽이 있으면 0이 아님 → continue
- 8-2) visited 없으면? 같은 칸 반복 삽입 → 큐 폭발, 출구 없으면 무한 루프

## 9번. 코드 수정 (12점)

- 9-1) 목적지 여러 개 → 집합으로 받고 `if (x, y) in targets:`로. BFS가 거리순이라 처음 꺼낸 목적지가 가장 가까움
- 9-2) 중간 지점 필수 → BFS 두 번: (S→M) + (M→E), 거리 합, 경로 `path1 + path2[1:]`

## 10번. reconstruct_path (9점)

```py
def reconstruct_path(parent, ex, ey):
    path = []
    current = (ex, ey)
    # (a)
    while current is not None:
        path.append(current)
        x, y = current
        current = parent[x][y]
    path.reverse()
    return path
```

- parent를 따라 도착→시작으로 거슬러 올라간 뒤 reverse
