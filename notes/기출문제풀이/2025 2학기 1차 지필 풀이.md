# 1번. 2차원 누적합으로 직사각형 평균 (15점)

N×N 이미지에서 직사각형 영역 픽셀 **평균**을 M번 구하기. 좌표는 1부터, x가 행.

## 1) 시간복잡도

- ① 매번 직접 더하기: `O(N² × M)`
- ② 누적합: `O(N² + M)` (만들기 O(N²) + 질문당 O(1))

## 2) 빈칸 (a)~(c)

```py
# (a) 위 + 왼 - 대각 + 나
S[a][b] = S[a-1][b] + S[a][b-1] - S[a-1][b-1] + img[a-1][b-1]

# (b) 전체 - 위 - 왼 + 대각
return S[x2][y2] - S[x1-1][y2] - S[x2][y1-1] + S[x1-1][y1-1]

# (c) 칸 개수 = 행 수 × 열 수 (양 끝 포함 → +1)
cnt = (x2 - x1 + 1) * (y2 - y1 + 1)
```

- 확인: `2 2 3 4` → 27, 6칸 → 4.5 ✔

# 2번. MinStack (15점)

스택 연산 + 최솟값을 O(1)에 돌려주는 `get_min()`. 스택 2개(stack, min_stack).

```py
class MinStack:
    def __init__(self):
        self.stack = []
        self.min_stack = []

    def push(self, val: int) -> None:
        self.stack.append(val)
        # (a)
        if not self.min_stack or val <= self.min_stack[-1]:
            self.min_stack.append(val)

    def pop(self) -> None:
        # (b)
        if self.stack[-1] == self.min_stack[-1]:
            self.min_stack.pop()
        self.stack.pop()

    def top(self) -> int:
        return self.stack[-1]

    def get_min(self) -> int:
        # (c)
        return self.min_stack[-1]
```

- (a) `<=`인 이유: 같은 최솟값이 두 번 들어오면 둘 다 기록. `<`로 하면 push(2),push(2),pop() 후 min_stack이 비어 get_min() 터짐
- (b) 빼기 전에 빠질 값이 현재 최솟값이면 min_stack에서도 빼기

# 3번. 빗물 가두기 (25점)

각 칸 수위 = min(왼쪽 최대, 오른쪽 최대), 고인 물 = 수위 − 블록 높이.

## 1) 물이 절대 안 고이는 블록

- ① 맨 양 끝 (막아줄 벽 없음)
- ② 자기 높이 = 왼쪽 최대 (왼쪽에 더 높은 벽 없음)
- ③ 자기 높이 = 오른쪽 최대
- → `min(왼쪽 최대, 오른쪽 최대) = 자기 높이`면 고인 물 0

## 2) 브루트포스

```py
def trap(height):
    n, water = len(height), 0
    for i in range(1, n - 1):
        left_max = 0
        for j in range(0, i + 1):
            if height[j] > left_max:
                left_max = height[j]
        right_max = 0
        for j in range(i, n):
            if height[j] > right_max:
                right_max = height[j]
        water += max(0, min(left_max, right_max) - height[i])
    return water
```

- ① O(n²) ② `[3,2,1]`→0, `[2,2,2]`→0 ③ 필요한 세 값: left_max, right_max, height[i]

## 3) 투 포인터 O(n)

```py
def trap(height):
    left, right = 0, len(height) - 1
    left_max, right_max = 0, 0
    water = 0
    while left <= right:
        if height[left] < height[right]:
            if height[left] >= left_max:
                left_max = height[left]
            else:
                water += left_max - height[left]
            left += 1
        else:
            if height[right] >= right_max:
                right_max = height[right]
            else:
                water += right_max - height[right]
            right -= 1
    return water
```

- ③ height[left] < height[right]일 때 left를 옮겨도 되는 이유: 오른쪽에 이미 더 높은 벽이 있어 left 칸의 물은 `left_max - height[left]`로 확정됨

# 4번. Flood Fill (25점)

시작 픽셀과 같은 색이면서 상하좌우로 이어진 픽셀을 new_color로.

## 1) 색이 안 바뀌는 픽셀

- ① start_color와 다른 색 ② 같은 색이어도 시작과 안 이어진 것 ③ new_color == start_color면 전부 그대로

## 3) ① dfs 빈칸

```py
def dfs(r, c):
    if image[r][c] != start_color:     # (a)
        return
    image[r][c] = new_color            # (b)
    for nr, nc in [(r - 1, c), (r + 1, c), (r, c - 1), (r, c + 1)]:
        if 0 <= nr < rows and 0 <= nc < cols:   # (c)
            dfs(nr, nc)
```

- (a)가 visited 역할 (이미 바꾼 칸도 걸러짐)

## 3) ② 예외 처리 (가) `if start_color == new_color: return image` 없으면?

- start_color == new_color면 색을 바꿔도 그대로 → 방문 표시 안 됨 → (1,1)↔(1,2) 무한 재귀 → RecursionError

# 5번. 로봇 요청 처리: 힙 (20점)

원점(0)에 가장 가까운 요청부터 처리. 거리 같으면 음수(왼쪽) 먼저.

```py
for _ in range(n):
    line = input().strip()
    # (a)
    if line == "Do It":
        if heap:
            dist, pos = heappop(heap)
            result.append(str(pos))
        else:
            result.append("NO REQUEST")
    else:                                # "REQ x"
        pos = int(line.split()[1])
        heappush(heap, (abs(pos), pos))
```

- 힙에 `(거리, 위치)` → 거리 같으면 위치 작은 것(음수) 먼저. O(N log N)
