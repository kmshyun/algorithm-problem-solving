# ✍️ 손코딩 팁

> 출처: Notion "2026 프로그래밍과 문제해결"

## ⏰ 시험 구조에서 나오는 결론

50분 / 5~6문제 / 전부 손코딩 → **한 문제당 8분**. 생각해서 푸는 시험이 아니라 **외운 걸 꺼내 쓰는 시험**.

- 빈칸 문제는 한 문제당 3~5분 안에 끊고, 처음부터 짜는 문제에 남은 시간 몰아주기
- 푸는 순서: **빈칸 먼저 → 전체 구현 나중**

## 1. 빈칸은 '정해진 자리'에 뚫린다

| 뚫리는 자리 | 예시 |
|-------------|------|
| 자료구조 초기화 | `dist = [INF] * (n+1)`, `visited = [False] * n` |
| 반복문 범위 | `for i in range(1, n+1)` ← 0부터? 1부터? n? n+1? |
| 갱신식 | `dist[nxt] = d + w`, `pre[i] = pre[i-1] + a[i]` |
| 조건문 | `if d > dist[cur]: continue`, `if visited[nxt]: continue` |
| 넣고 꺼내는 연산 | `heapq.heappush(pq, (nd, nxt))`, `q.popleft()` |
| 재귀 종료조건 | `if depth == n: return` |
| 백트래킹 복구 | `used[i] = False` (선택 해제) |

## 2. 단원별 '뼈대' 통암기 리스트

단원마다 뼈대 코드 **딱 1개씩**만 완벽하게. 손으로 3번 베껴 쓰기.

- 해싱 → `cnt[x] = cnt.get(x, 0) + 1`
- 스택 → 괄호 짝 맞추기
- 큐·데크 → `deque()`, `append`/`popleft`/`appendleft`/`pop`
- 누적합 → `pre[i] = pre[i-1] + a[i]`, 구간합 `pre[r] - pre[l-1]`
- 투 포인터 → `while r < n:` 안에서 r 늘리고, 조건 깨지면 l 당기기
- 재귀 → 종료조건 → 재귀호출 → 반환값 조립
- 백트래킹 → **선택 → 재귀 → 선택 해제** 3줄 구조
- BFS → `q = deque([s]); visited[s] = True` → `while q:`
- 다익스트라 → `dist` 배열 + `heapq` + `if d > dist[cur]: continue`

> 💡 BFS와 다익스트라는 뼈대가 거의 같다 (`deque` ↔ `heapq`, `visited` ↔ `dist`). 나란히 놓고 외우면 절반의 노력.

## 3. 손으로 쓸 때의 기술

- 파이썬은 **들여쓰기가 곧 문법** → 블록 시작하면 연필로 세로 점선 긋기
- **한 줄 걸러 쓰기**: 빠뜨린 줄 끼워 넣을 공간 확보
- **지우지 말고 두 줄 긋기**
- **변수명은 짧게**: `dist`, `cur`, `nxt`, `q`, `pre`
- 제출 전 콜론 `:`만 훑는 검사 1회

## 4. 처음부터 짜는 문제 공략

1. 문제 읽고 "이건 무슨 단원이지?"부터 판단
2. 여백에 뼈대만 한글로: `입력받기 → 그래프 만들기 → BFS → 출력`
3. 그다음 코드로 옮기기 (막혀도 부분점수)
4. 입력 파싱은 마지막에 써도 됨. 핵심 알고리즘부터
