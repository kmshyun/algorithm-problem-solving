# 3️⃣ Backtracking

- 가능한 상태 정의 → 후보 탐색 → 제약조건 불만족이면 가지치기
- Queen처럼 복잡한 건 ❌, 기본 문제(암호 만들기 등). 빈칸 + 서술

```py
def backtrack():
    if len(state) == M:        # 완성 조건
        print(*state)
        return
    for i in range(1, N + 1):  # 후보 탐색
        if used[i]:            # 가지치기
            continue
        state.append(i)        # 선택
        used[i] = True
        backtrack()            # 탐색
        state.pop()            # 복원
        used[i] = False
```

> ⭐ 서술 예시: **복원 안 하면?** `state.pop()`을 빼면 앞에서 고른 값이 남아 길이가 M을 넘어 이후 수열 누락. `used[i]=False`를 빼면 한 번 쓴 값을 다른 가지에서 못 써 답 일부 누락. 복원은 다음 후보를 같은 조건에서 시도하게 함.

# 4️⃣ DFS / BFS

공통점: 그래프 탐색 · visited 확인 필요. 차이점: 탐색 순서.

|  | DFS | BFS |
|--|-----|-----|
| 순서 | 깊이 우선 | 너비 우선 |
| 구현 | 재귀(스택) | Queue |
| 최단경로 | ❌ | ⭕ (가중치 없을 때 간선 수 기준) |

> ⚠️ "최단경로 + Queue"는 **BFS** (DFS 아님).

```py
graph = {v: [] for v in vertices}     # 알파벳 정점 → dict
for _ in range(M):
    u, v = input().split()
    graph[u].append(v)
    graph[v].append(u)
```

- DFS/BFS 각 처리 절차가 왜 필요한지 설명 가능해야 (visited 왜? 정렬 왜? 큐/재귀 왜?)

# 5️⃣ 🔥 Weighted Graph + Dijkstra (약 30점)

- 다익스트라 = 가중 그래프 최단경로
- 우선순위 큐를 쓰는 이유: `pop`하면 항상 최솟값 = 가중치 최소 경로 우선 탐색
- heap이 완전히 빌 때까지 → 모든 경로 탐색. 이미 짧은 경로가 확정됐으면 가지치기

```py
while heap:
    d, cur = heapq.heappop(heap)     # 비용 최소부터
    if d > times[cur]:               # 이미 더 짧은 경로 → 가지치기
        continue
    for nxt, w in graph[cur]:
        nd = d + w
        if nd < times[nxt]:
            times[nxt] = nd
            heapq.heappush(heap, (nd, nxt))
```

## 서술 대비

- **Q1. 우선순위 큐 왜?**: 누적 비용 최소 후보부터 탐색해야 최단 보장. pop이 항상 최솟값을 꺼냄.
- **Q2. 최적 아닌 heap 항목 처리?**: 더 좋은 경로로 갱신되면 예전 항목이 남음 → 꺼낼 때 `times`보다 크면 가지치기 (시간·효율).
- **Q3. heap 빌 때까지 도는 이유?**: 모든 정점의 최단 거리 확정을 위해.
