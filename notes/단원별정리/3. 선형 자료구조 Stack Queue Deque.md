# 1. 스택 (Stack)

## 스택이란?

- 한쪽 끝(위)에서만 넣고 빼는 자료구조
- LIFO (Last In, First Out, 후입선출): 마지막에 넣은 것이 가장 먼저 나옴
- 비유: 접시 쌓기. 새 접시는 맨 위에 올리고, 꺼낼 때도 맨 위부터
- 일상 예: 브라우저 뒤로 가기, Ctrl+Z 되돌리기, 함수 호출(재귀 호출 스택)

```txt
push 1 → push 2 → push 3 → pop

 |   |     |   |     | 3 |     |   |
 |   |     | 2 |     | 2 |     | 2 |   ← pop하면 맨 위 3이 나옴
 | 1 |     | 1 |     | 1 |     | 1 |
 +---+     +---+     +---+     +---+
```

## 스택 연산

- push: 맨 위에 넣기
- pop: 맨 위를 꺼내기
- peek (top): 맨 위를 꺼내지 않고 보기만
- empty: 비었는지 확인

## 코드

```py
s = []

s.append(1)     # push
s.append(2)
s.append(3)

print(s[-1])    # peek → 3
print(s.pop())  # pop → 3
print(s.pop())  # pop → 2

if s:           # 비어 있지 않으면
    print(s.pop())
else:
    print("EMPTY")
```

## 코드 설명

- 파이썬은 리스트가 그대로 스택 역할을 함. 리스트의 끝 = 스택의 맨 위
- `append(x)`: 끝에 추가 → push
- `pop()`: 끝에서 꺼내서 돌려줌 → pop
- `s[-1]`: 끝 원소 보기 → peek
- `if s:` : 리스트가 비어 있으면 False → 빈 스택에서 pop하기 전에 꼭 확인

# 2. 큐 (Queue)

## 큐란?

- 한쪽(뒤)으로 넣고 반대쪽(앞)으로 빼는 자료구조
- FIFO (First In, First Out, 선입선출): 먼저 넣은 것이 먼저 나옴
- 비유: 음식점 대기줄. 먼저 온 사람이 먼저 입장
- 일상 예: 프린터 대기열, 고객센터 대기, BFS

```txt
      앞(front)           뒤(rear)
      
꺼냄 <-- [ 1 ] [ 2 ] [ 3 ] [ 4 ]  <-- 넣음

      popleft()          append()
```

## 코드

```py
from collections import deque
import sys
input = sys.stdin.readline

a = int(input())
l = input().split()
q = deque()

for i in l:
    q.append(i)         # enqueue: 뒤에 넣기

for i in range(a):
    print(q.popleft())  # dequeue: 앞에서 꺼내기 → 넣은 순서 그대로 나옴
```

## 코드 설명

- `deque()`: 파이썬에서 큐는 `collections.deque`로 만듦
- `append(x)`: 뒤에 넣기
- `popleft()`: 앞에서 꺼내기
- 리스트로 큐를 만들면 안 되는 이유: `pop(0)`은 앞을 빼고 나머지를 전부 한 칸씩 당겨서 O(n). 원소가 많으면 시간 초과
- `input = sys.stdin.readline`: 입력이 많을 때 빠르게 읽는 방법. 줄 끝의 `\n`이 같이 들어오지만 `int()`, `split()`은 알아서 무시함

# 3. 데크 (Deque)

## 데크란?

- Double-Ended Queue: 앞과 뒤 양쪽 모두에서 넣고 뺄 수 있는 자료구조
- 스택처럼도(뒤에서 넣고 뒤에서 빼기), 큐처럼도(뒤에서 넣고 앞에서 빼기) 쓸 수 있음
- 파이썬의 `deque`가 바로 이것

```txt
appendleft() -->  [ 1 ][ 2 ][ 3 ] <-- append()
popleft()    <--                   --> pop()
```

## 코드

```py
from collections import deque
a = int(input())
q = deque()

for i in range(a):
    c = input().split()
    if c[0] == "REMOVE_LEFT":
        if q:
            print(q.popleft())
        else:
            print("EMPTY")
            
    elif c[0] == "REMOVE_RIGHT":
        if q:
            print(q.pop())
        else:
            print("EMPTY")
            
    elif c[0] == "ADD_LEFT":
        q.appendleft(c[1])
    else:               # ADD_RIGHT
        q.append(c[1])
```

## 코드 설명

- 연산 4개
  - `appendleft(x)`: 앞에 넣기
  - `append(x)`: 뒤에 넣기
  - `popleft()`: 앞에서 꺼내기
  - `pop()`: 뒤에서 꺼내기
- 네 연산 모두 O(1)
- `input().split()`으로 명령어와 값을 한 번에 나눠 받음 → `c[0]`은 명령, `c[1]`은 값
- 꺼내는 명령 앞에는 항상 `if q:`로 빈 데크인지 확인

## 보너스: rotate

- `q.rotate(-1)`: 맨 앞 원소를 맨 뒤로 (왼쪽으로 한 칸 회전)
- `q.rotate(1)`: 맨 뒤 원소를 맨 앞으로 (오른쪽으로 한 칸 회전)

# 4. 시간 복잡도 / 주의할 점

## 시간 복잡도

- 스택 (리스트): `append`, `pop()`, `s[-1]` 모두 O(1)
- 큐·데크 (deque): `append`, `appendleft`, `pop`, `popleft` 모두 O(1)
- 리스트의 `pop(0)`, `insert(0, x)`: O(n) → 큐 대신 쓰면 안 됨
- deque의 중간 인덱싱 `q[i]`: 가운데로 갈수록 느림

## 주의할 점

- 빈 스택/큐에서 `pop`, `popleft`, `s[-1]`을 하면 IndexError → 꺼내기 전에 `if s:` 확인이 습관이 되어야 함
- 문제에서 "비어 있으면 EMPTY 출력" 같은 조건이 거의 항상 나옴
- 어떤 걸 쓸지 고르는 기준
  - 가장 최근 것부터 처리 / 되돌리기 / 짝 맞추기 → 스택
  - 먼저 온 순서대로 처리 → 큐
  - 양쪽 끝을 다 건드림 / 회전 → 데크

# 5. 스택, 큐, 데크의 활용

## 활용 ① 되돌리기 (UNDO)

- LIFO → 작업을 스택에 쌓고 UNDO마다 pop

```py
n = int(input())
s = []
for i in range(n):
    c = input().split()
    if c == ["UNDO"]:
        if s:
            k = s.pop()
            print(k[1])     # 취소한 작업 내용
        else:
            print('EMPTY')
    else:                   # 작업 명령: 통째로 스택에 기록
        s.append(c)
```

## 활용 ② 괄호 검사

- 여는 괄호는 push, 닫는 괄호는 스택 맨 위와 비교 후 pop
- 올바르지 않은 경우 3가지: ① 닫는데 스택 비었음 `())` ② 짝 안 맞음 `(]` ③ 끝났는데 여는 괄호 남음 `(()`

### 한 종류 괄호 `( )`

```py
l = input()
s = []
m = True

for i in l:
    if i == '(':
        s.append(i)
    else:
        if not s:           # 경우 1
            m = False
            break
        s.pop()

if m and not s:             # 경우 3
    print("YES")
else:
    print("NO")
```

- 카운터 버전:

```py
l = input()
cnt = 0
m = True

for i in l:
    if i == '(':
        cnt += 1
    else:
        cnt -= 1
        if cnt < 0:
            m = False
            break

if m and cnt == 0:
    print("YES")
else:
    print("NO")
```

### 여러 종류 괄호 `( ) [ ] { }`

```py
l = input()
s = []
p = {')': '(', ']': '[', '}': '{'}   # 닫는 괄호 → 짝이 되는 여는 괄호
v = True

for c in l:
    if c in "({[":
        s.append(c)
    elif c in ")}]":
        if not s or s[-1] != p[c]:  # 경우 1, 2
            v = False
            break
        s.pop()

if v and not s:                     # 경우 3
    print("YES")
else:
    print("NO")
```

- 종류가 여러 개면 카운터로는 `([)]`를 못 잡음 → 스택 필요

## 활용 ③ 텍스트 편집기 (백스페이스)

```py
n = int(input())
s = []
for i in range(n):
    c = input().split()
    if c[0] == "TYPE":
        s.append(c[1])
    else:               # 지우기 명령
        if s:
            s.pop()

print(''.join(s) if s else "EMPTY")
```

## 활용 ④ 인접한 같은 문자 연쇄 제거

```py
l = input().strip()
s = []
for c in l:
    if s and s[-1] == c:
        s.pop()
    else:
        s.append(c)

print(''.join(s) if s else "EMPTY")
```

## 활용 ⑦ 원형 회전 (데크)

```py
from collections import deque
a, b = map(int, input().split())
q = deque(input().split())

for i in range(b):
    c = input().split()
    if c[0] == 'LEFT':
        if q:
            q.append(q.popleft())       # q.rotate(-1)
    elif c[0] == 'RIGHT':
        if q:
            q.appendleft(q.pop())       # q.rotate(1)
    else:
        print(q.popleft() if q else "EMPTY")
```

# 6. 예제들

## 예제 1. 역행렬

```py
s1 = input()
s2 = input()
st = []

for c in s1 + s2:
    if c == '~':
        top = st.pop()
        if st and st[-1] == top:
            st.pop()
        else:
            st.append(top + '~')
    else:
        if st and st[-1] == c + '~':
            st.pop()
        else:
            st.append(c)

if not st:
    print("YES")
else:
    print("NO")
```

## 예제 2. 후위 표기식 계산

- 숫자는 push, 연산자가 나오면 맨 위 두 개를 pop. 먼저 pop한 게 오른쪽!

```py
tokens = input().split()
stack = []

for token in tokens:
    try:
        stack.append(int(token))    # 숫자면 push
    except ValueError:              # 연산자
        right = stack.pop()         # 먼저 꺼낸 게 오른쪽!
        left = stack.pop()

        if token == '+':
            stack.append(left + right)
        elif token == '-':
            stack.append(left - right)
        elif token == '*':
            stack.append(left * right)
        elif token == '/':
            stack.append(int(left / right))

print(stack[0])
```

## 예제 3. 쇠막대기 자르기

```py
line = input()
stack = []
cnt = 0

for i in range(len(line)):
    if line[i] == '(':
        stack.append('(')
    else:
        stack.pop()
        if line[i - 1] == '(':      # 레이저
            cnt += len(stack)
        else:                       # 막대기 끝
            cnt += 1

print(cnt)
```

## 예제 4. 화학식량 계산

```py
formula = input()
atomic_mass = {"H": 1, "C": 12, "O": 16}

stack = []
count_str = ''


def apply_multiplier(stack, count_str):
    """버퍼에 숫자가 있으면 스택 맨 위 값에 곱하고, 버퍼를 비운다."""
    if count_str:
        top = stack.pop()
        stack.append(top * int(count_str))
    return ''


for ch in formula:
    if ch.isdigit():
        count_str += ch
    else:
        count_str = apply_multiplier(stack, count_str)

        if ch in atomic_mass:
            stack.append(atomic_mass[ch])
        elif ch == '(':
            stack.append('(')
        elif ch == ')':
            group_sum = 0
            while stack[-1] != '(':
                group_sum += stack.pop()
            stack.pop()                   # '(' 제거
            stack.append(group_sum)

count_str = apply_multiplier(stack, count_str)
print(sum(stack))
```

## 예제 5. 스택 수열

```py
n = int(input())
target = list(map(int, input().split()))

next_num = 1        # 다음에 push할 수
stack = []
ops = []

for num in target:
    while next_num <= num:          # num까지 몰아서 push
        stack.append(next_num)
        ops.append('+')
        next_num += 1
    if stack and stack[-1] == num:
        stack.pop()
        ops.append('-')
    else:
        print('NO')
        exit()

print(' '.join(ops))
```

## 예제 6. 데크 명령 처리

```py
from collections import deque
n = int(input())
dq = deque()

for _ in range(n):
    cmd = input().split()
    if cmd[0] == 'push_front':
        dq.appendleft(cmd[1])
    elif cmd[0] == 'push_back':
        dq.append(cmd[1])
    elif not dq:                    # 여기부터는 전부 "비면 -1"
        print(-1)
    elif cmd[0] == 'pop_front':
        print(dq.popleft())
    elif cmd[0] == 'pop_back':
        print(dq.pop())
    elif cmd[0] == 'front':
        print(dq[0])
    else:                           # back
        print(dq[-1])
```

## 예제 7. 카드 버리기

```py
from collections import deque
n = int(input())
cards = deque(range(1, n + 1))
discarded = []

while len(cards) > 1:
    discarded.append(cards.popleft())   # 맨 위 버리기
    cards.append(cards.popleft())       # 다음 맨 위를 맨 아래로

discarded.append(cards[0])
print(*discarded)
```

## 예제 8. 요세푸스 문제

### 풀이 1. 큐

```py
from collections import deque
n, k = map(int, input().split())
people = deque(range(1, n + 1))
removed = []

while people:
    for _ in range(k - 1):
        people.append(people.popleft())
    removed.append(people.popleft())

print(*removed)
```

### 풀이 2. 리스트 인덱스

```py
n, k = map(int, input().split())
people = list(range(1, n + 1))
removed = []
idx = 0

for _ in range(n):
    idx = (idx + k - 1) % len(people)
    removed.append(people.pop(idx))

print(*removed)
```
