# 📝 1. 프로그램 설계와 명세

> 출처: Notion "2026 프로그래밍과 문제해결"

# 0. 1차시 활동 개요

- 주제: "CO2 농도가 높으면 환기한다"를 프로그램으로 만들기
- 핵심: 한 번에 다 짜지 않고, 명세를 정하고 → 작은 문제로 쪼개고 → 하나씩 구현하고 → 합치고 → 테스트하는 과정을 연습

# 1. 문제 분석과 명세

- 상황: 13:00부터 5분 간격으로 교실 CO2 농도(ppm)를 n번 측정
- 입력 명세
  - 첫째 줄: 측정 횟수 n
  - 둘째 줄: 측정값 n개 (공백 구분 정수)
- 기준
  - 1000 이상 1300 미만: 경고
  - 1300 이상: 위험
- 환기 조건: 위험이 한 번이라도 있거나, 경고가 3회 이상이면 환기 필요 (True)
- 출력 명세
  - 평균 농도 (소수 첫째 자리 반올림)
  - 최댓값과 그 측정 시각 (최댓값이 여러 번이면 마지막 시각)
  - 1000 이상인 측정 횟수
  - 경고·위험이 발생한 시각 목록 (없으면 NONE)
  - 환기 필요 여부 (True/False)
- 인덱스 → 시각 변환: i번째 측정은 13:00 + 5×i분 → 시 = 13 + (5i)//60, 분 = (5i)%60, 분은 항상 두 자리(13:05)

# 2. 문제 쪼개기 (분해)

- 큰 문제 하나를 서로 독립적인 작은 문제 3개로 나눔
  - ps01: 평균과 1000 이상 개수 → "전체를 한 번 훑으며 합계·개수 세기"
  - ps02: 최댓값과 그 시각 → "최댓값 + 위치 찾기" + "인덱스를 시각으로 바꾸기"
  - ps03: 경고/위험 시각 목록과 환기 여부 → "조건에 맞는 위치 모으기" + "여러 조건 조합해서 판단하기"
- 이렇게 나누면 각각을 따로 테스트할 수 있고, 어디서 틀렸는지 찾기 쉬움

# 3. 부분 문제 구현

## 01. 평균과 1000 이상 개수

```py
n = int(input())
l = list(map(int, input().split()))

s = 0
w = 0
for i in l:
    s += i
    if i >= 1000:
        w += 1

print(round(s / n, 1))
print(w)
```

- 반복문 한 번으로 합계 s와 개수 w를 동시에 구함 (누적 변수 패턴)
- `round(s / n, 1)`: 소수 첫째 자리까지 반올림

## 02. 최댓값과 그 시각

```py
n = int(input())
l = list(map(int, input().split()))

m = l[0]
id = 0
for i, val in enumerate(l):
    if m <= val:
        m = val
        id = i

h = 13 + (5 * id) // 60
min = (5 * id) % 60

print(m)
print(f"{h}:{min:02d}")
```

- `m <= val`로 비교해서 같은 값이 또 나오면 갱신 → 최댓값이 여러 번이면 마지막 위치가 남음
- `enumerate(l)`: 값과 인덱스를 같이 꺼냄
- `f"{min:02d}"`: 분을 항상 두 자리로 출력 (5 → 05)
- 수정한 부분
  - 원래는 `id = l.index(i)`였는데, `index`는 그 값이 처음 나온 위치를 돌려줘서 최댓값이 여러 번이면 첫 시각이 나오는 버그가 있었음 (1200 900 1200 → 13:00). enumerate로 인덱스를 직접 받아서 해결
  - 쓰이지 않던 `h = 13`, `min = 00` 초기화 삭제
  - 문자열 길이 검사로 '0' 붙이던 부분을 `:02d` 포맷으로 정리

## 03. 경고/위험 시각과 환기 여부

```py
n = int(input())
l = list(map(int, input().split()))

m = []
k = []
v = False
w = 0

for i, val in enumerate(l):
    if val >= 1300:
        v = True
        m.append(i)
    elif 1000 <= val < 1300:
        w += 1
        m.append(i)
        if w >= 3:
            v = True

for i in m:
    h = 13 + (5 * i) // 60
    min = (5 * i) % 60
    k.append(f"{h}:{min:02d}")

print("NONE" if not m else ' '.join(k))
print(v)
```

- 1단계: 경고·위험인 인덱스를 리스트 m에 모음
- 2단계: 모은 인덱스를 시각 문자열로 바꿔 k에 모음
- 위험(1300 이상)이면 바로 v = True, 경고는 w로 세다가 3 이상이면 v = True
- 리스트가 비었으면 NONE 출력: `"NONE" if not m else ...`
- 수정한 부분
  - 경고 조건 `1300 >= l[i] >= 1000`을 명세 그대로 `1000 <= val < 1300`으로
  - `range(len(l))` + `l[i]` 대신 `enumerate`
  - `w >= 3` 검사를 경고가 늘어날 때만 하도록 elif 안으로 이동

# 통합 Source Code

```py
n = int(input())
l = list(map(int, input().split()))

# 1) 평균, 1000 이상 개수
s = sum(l)
w = sum(1 for i in l if i >= 1000)

# 2) 최댓값과 그 시각
m = l[0]
id = 0
for i, val in enumerate(l):
    if m <= val:
        m = val
        id = i
h = 13 + (5 * id) // 60
min = (5 * id) % 60

print(round(s / n, 1))
print(m)
print(f"{h}:{min:02d}")
print(w)

# 3) 경고/위험 시각, 환기 여부
m = []
k = []
v = False
w = 0
for i, val in enumerate(l):
    if val >= 1300:
        v = True
        m.append(i)
    elif 1000 <= val < 1300:
        w += 1
        m.append(i)
        if w >= 3:
            v = True

for i in m:
    h = 13 + (5 * i) // 60
    min = (5 * i) % 60
    k.append(f"{h}:{min:02d}")

print("NONE" if not m else ' '.join(k))
print(v)
```

- 부분 문제 3개를 명세의 출력 순서대로 이어 붙임
- 부분 코드에서 개선된 점
  - `sum(l)`, `sum(1 for i in l if i >= 1000)`: 내장 함수로 합계·개수를 한 줄에
  - 계산과 출력을 구간별로 묶고 주석으로 어느 부분 문제인지 표시
- 주의: m, w를 2)에서는 최댓값·개수로, 3)에서는 인덱스 목록·경고 횟수로 다시 씀. 그래서 3) 시작할 때 반드시 다시 초기화해야 함

# 번외 : 숏코딩 버전

```py
n, l = int(input()), [*map(int, input().split())]
T = lambda i: f"{13 + i // 12}:{i % 12 * 5:02d}"
m = max(l)
A = [i for i, x in enumerate(l) if x >= 1000]

print(round(sum(l) / n, 1))
print(m)
print(T(n - 1 - l[::-1].index(m)))
print(len(A))
print(' '.join(T(i) for i in A) if A else "NONE")
print(any(x >= 1300 for x in l) or sum(1000 <= x < 1300 for x in l) >= 3)
```

- 같은 명세를 최대한 짧게 쓴 버전. 쓰인 기법
  - `T = lambda i: ...`: 인덱스→시각 변환을 함수로 한 번만 정의. 한 시간에 12번 측정하니까 시 = i // 12, 분 = (i % 12) × 5
  - `max(l)`: 최댓값 내장 함수
  - `n - 1 - l[::-1].index(m)`: 뒤집은 리스트에서 처음 위치 = 원래 리스트에서 마지막 위치
  - 리스트 컴프리헨션으로 1000 이상 위치 A를 한 번에 모음
  - `any(...)`: 하나라도 만족하면 True. True를 더하면 1로 세지는 성질로 경고 개수 계산
- 숏코딩은 재미로만 보자

# 테스트와 디버깅

- 기본 테스트 입력

```txt
15
800 950 1020 1100 990 1250 1310 900 1000 870 760 1400 1100 980 700
```

- 꼭 넣어볼 경계 케이스
  - 최댓값이 여러 번 나오는 경우 (1200 900 1200) → ps02 버그를 찾은 케이스
  - 경고·위험이 하나도 없는 경우 (400 500 600) → ldy0001_short 버그를 찾은 케이스
  - 값이 정확히 1000, 1300인 경우 → 이상/미만 경계 확인
  - 경고가 딱 2번 / 3번인 경우 → 환기 조건 경계 확인
  - 12번째 이후 측정 (14:00 넘어가는 경우) → 시각 변환 확인

# 정리: 1차시에서 배운 것

- 명세를 먼저 정확히 적어야 코드가 흔들리지 않음 (이상/미만, 동점 처리, 출력 형식)
- 큰 문제를 작은 문제로 쪼개면 각각 테스트하고 고치기 쉬움
- 합칠 때 더 좋은 도구로 다듬을 수 있음 (enumerate, sum, f-string 포맷)
- 짧게 줄이는 것보다 읽기 쉽고 명세와 똑같이 보이는 코드가 더 중요함
- 경계 케이스 테스트로 버그를 찾음
