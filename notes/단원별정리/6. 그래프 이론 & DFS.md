# 🕸️ 6. 그래프 이론 & DFS

> 출처: Notion "2026 프로그래밍과 문제해결"

# 1. 인접 리스트

## 그래프란?

- 정점(노드)과 간선(연결)으로 이루어진 구조
- 무방향: a–b면 양방향 / 방향: a→b만

## 저장 방법 2가지

- 인접 행렬: n×n 리스트, `g[a][b] = 1`. 메모리 O(n²), 연결 확인 O(1)
- 인접 리스트: 정점마다 "연결된 정점 목록"만. 메모리 O(n + k)
- 문제의 그래프는 보통 희소 → 인접 리스트가 기본값

## 코드

```py
n = int(input())
k = int(input())
g = [[] for _ in range(n+1)]

for i in range(k):
    a, b = map(int, input().split())
    g[a].append(b)
    g[b].append(a)
```

- `[[] for _ in range(n+1)]` (0번 칸 안 씀). `[[]] * (n+1)`은 금지(전부 같은 리스트)
- 방향 그래프면 `g[a].append(b)`만

# 2. DFS

## DFS란?

- 한 방향으로 끝까지 파고들었다가 막히면 직전 갈림길로 되돌아옴
- 재귀로 구현하면 "되돌아오기"가 자동

## 코드

```py
n = int(input())
k = int(input())
g = [[] for _ in range(n+1)]

for i in range(k):
    a, b = map(int, input().split())
    g[a].append(b)
    g[b].append(a)

visited = [False] * (n+1)

def dfs(s):
    visited[s] = True
    for i in g[s]:
        if not visited[i]:
            dfs(i)

dfs(1)      # 1번 정점에서 시작
```

## 시간 복잡도 / 주의

- O(n + k)
- 파이썬 재귀 깊이 제한 ~1000 → `import sys; sys.setrecursionlimit(10**6)`
- 방문 순서가 정해진 문제면 `g[i].sort()`

# 3. 2차원 배열(격자)에서의 DFS

## 방향 배열

```py
dx = [-1, 1, 0, 0]   # 상 하 좌 우
dy = [0, 0, -1, 1]

for d in range(4):
    nx, ny = x + dx[d], y + dy[d]
```

- 8방향: `dx = [-1,-1,-1,0,0,1,1,1]`, `dy = [-1,0,1,-1,1,-1,0,1]`

## 이웃 검사 3가지 (순서 중요!)

1. 범위 안인가: `0 <= nx < R and 0 <= ny < C`
2. 안 갔나: `not visited[nx][ny]`
3. 갈 수 있는 칸: `a[nx][ny] == 1`

- 범위 검사를 무조건 맨 앞에! (short-circuit) — nx=-1이면 `visited[-1]`로 엉뚱한 칸 검사 버그

## 기본 코드: 섬 개수 세기

```py
import sys
sys.setrecursionlimit(10**6)
input = sys.stdin.readline

R, C = map(int, input().split())
a = [list(map(int, input().split())) for _ in range(R)]   # 1: 땅, 0: 바다
visited = [[False] * C for _ in range(R)]

dx = [-1, 1, 0, 0]
dy = [0, 0, -1, 1]

def dfs(x, y):
    visited[x][y] = True
    for d in range(4):
        nx, ny = x + dx[d], y + dy[d]
        if 0 <= nx < R and 0 <= ny < C and not visited[nx][ny] and a[nx][ny] == 1:
            dfs(nx, ny)

l = 0
for i in range(R):
    for j in range(C):
        if a[i][j] == 1 and not visited[i][j]:   # 새 섬의 시작점
            dfs(i, j)
            l += 1

print(l)
```

## 응용: 섬마다 크기 구하기

```py
def dfs(x, y):
    visited[x][y] = True
    cnt = 1                      # 나 자신
    for d in range(4):
        nx, ny = x + dx[d], y + dy[d]
        if 0 <= nx < R and 0 <= ny < C and not visited[nx][ny] and a[nx][ny] == 1:
            cnt += dfs(nx, ny)
    return cnt
```

- 격자가 1000×1000처럼 크면 재귀 깊이 터질 수 있음 → BFS가 안전
- "최소 몇 칸?" 최단거리면 BFS

# 4. DFS의 활용

## 활용 ① 트리의 부모 구하기

```py
parent = [0] * (n + 1)

def dfs(s):
    visited[s] = True
    for i in g[s]:
        if not visited[i]:
            parent[i] = s
            dfs(i)
```

## 활용 ② 연결 요소 구하기

```py
visited = [False] * (n+1)
l = 0

def dfs(s):
    visited[s] = True
    for i in g[s]:
        if not visited[i]:
            dfs(i)

for i in range(1,n+1):
    if not visited[i]:
        dfs(i)
        l += 1

print(l)
```

## 활용 ③ 공통 조상 구하기 (LCA)

```py
import sys
sys.setrecursionlimit(10**6)
input = sys.stdin.readline

n = int(input())
g = [[] for _ in range(n + 1)]

for _ in range(n - 1):
    a, b = map(int, input().split())
    g[a].append(b)
    g[b].append(a)

parent = [0] * (n + 1)
depth = [-1] * (n + 1)

def dfs(s, d):
    depth[s] = d
    for nxt in g[s]:
        if depth[nxt] == -1:
            parent[nxt] = s
            dfs(nxt, d + 1)

dfs(1, 0)

def lca(a, b):
    if depth[a] > depth[b]:
        a, b = b, a
    while depth[a] != depth[b]:
        b = parent[b]
    while a != b:
        a = parent[a]
        b = parent[b]
    return a

u, v = map(int, input().split())
print(lca(u, v))
```

- `dist(u, v) = depth[u] + depth[v] - 2 * depth[LCA]`

n = int(input())
g = [[] for _ in range(n + 1)]

for _ in range(n - 1):

def dfs(s, d):
    for i, w in g[s]:
        if distance[i] == -1:
            distance[i] = distance[s] + w
            dfs(i, d + w)

distance = [-1] * (n + 1)
distance[1] = 0

## 예제 3. 오목 (한 방향 직진)

```py
import sys

g = []
for _ in range(19):
    g.append(input().split())

dx = [0, 1, 1, -1]
dy = [1, 0, 1, 1]

def dfs(x, y, d, c):
    nx = x + dx[d]
    ny = y + dy[d]
    if 0 <= nx < 19 and 0 <= ny < 19 and g[nx][ny] == c:
        return 1 + dfs(nx, ny, d, c)
    return 1

for i in range(19):
    for j in range(19):
        if g[i][j] != '0':
            color = g[i][j]
            for d in range(4):
                cnt = dfs(i, j, d, color)
                if cnt == 5:
                    px = i - dx[d]
                    py = j - dy[d]
                    if 0 <= px < 19 and 0 <= py < 19 and g[px][py] == color:
                        continue   # 6목 이상
                    print(color)
                    print(i+1, j+1)
                    sys.exit(0)

print(0)
```

- 주의: 배열 값은 문자열(`'0'`). 오목은 한 돌이 여러 방향에 쓰여서 visited 쓰면 안 됨. 진행 방향 d를 인자로 넘겨 한 걸음씩 직진

## 예제 4. 지뢰찾기

```py
import sys

g = []
for _ in range(9):
    g.append(input().split())

r, c = map(int, input().split())
r -= 1
c -= 1

dr = [-1, 1, 0, 0, -1, -1, 1, 1]
dc = [0, 0, -1, 1, -1, 1, -1, 1]

def cm(cr, cc):
    m = 0
    for i in range(8):
        nr = cr + dr[i]
        nc = cc + dc[i]
        if 0 <= nr < 9 and 0 <= nc < 9:
            if g[nr][nc] == '1':
                m += 1
    return m

board = [['_' for _ in range(9)] for _ in range(9)]
visited = [[False] * 9 for _ in range(9)]

def dfs(cr, cc):
    if g[cr][cc] == '1':
        board[cr][cc] = '-1'
        return
    visited[cr][cc] = True
    m = cm(cr, cc)
    board[cr][cc] = str(m)
    if m == 0:
        for i in range(8):
            nr = cr + dr[i]
            nc = cc + dc[i]
            if 0 <= nr < 9 and 0 <= nc < 9:
                if not visited[nr][nc] and g[nr][nc] != '1':
                    dfs(nr, nc)

dfs(r, c)

for row in board:
    print(*row)
```

- 지뢰찾기는 Flood Fill → visited 필수 (오목과 반대)

## 예제 5. 애니팡 (같은 숫자 3개 이상 덩어리 개수)

```py
import sys
sys.setrecursionlimit(10**6)
g = [list(map(int, input().split())) for _ in range(7)]

visited = [[False] * 7 for _ in range(7)]
dr = [1, -1, 0, 0]
dc = [0, 0, -1, 1]

def dfs(r, c, target):
    visited[r][c] = True
    count = 1
    for i in range(4):
        nr = r + dr[i]
        nc = c + dc[i]
        if 0 <= nr < 7 and 0 <= nc < 7:
            if not visited[nr][nc] and g[nr][nc] == target:
                count += dfs(nr, nc, target)
    return count

s = 0
for i in range(7):
    for j in range(7):
        if not visited[i][j]:
            num = g[i][j]
            size = dfs(i, j, num)
            if size >= 3:
                s += 1
print(s)
```

## 예제 6. 숫자별 가장 큰 덩어리 크기 (DFS + 딕셔너리)

```py
import sys
sys.setrecursionlimit(10**6)

n, m = map(int, input().split())
g = [list(map(int, input().split())) for _ in range(n)]

visited = [[False] * m for _ in range(n)]
dr = [1, -1, 0, 0]
dc = [0, 0, -1, 1]

def dfs(r, c, target):
    visited[r][c] = True
    count = 1
    for i in range(4):
        nr = r + dr[i]
        nc = c + dc[i]
        if 0 <= nr < n and 0 <= nc < m:
            if not visited[nr][nc] and g[nr][nc] == target:
                count += dfs(nr, nc, target)
    return count

max_sizes = {}

for i in range(n):
    for j in range(m):
        if not visited[i][j] and g[i][j] >= 0:
            num = g[i][j]
            size = dfs(i, j, num)
            if num not in max_sizes or size > max_sizes[num]:
                max_sizes[num] = size

for num in sorted(max_sizes.keys()):
    print(num, max_sizes[num])
```

## 예제 7. 칠해지지 않은 영역의 개수와 넓이

```py
import sys
sys.setrecursionlimit(10**6)
input = sys.stdin.readline

r, c, k = map(int, input().split())
g = [[0] * c for _ in range(r)]

for _ in range(k):
    x1, y1, x2, y2 = map(int, input().split())
    for i in range(y1, y2):
        for j in range(x1, x2):
            g[i][j] = 1

dr = [1, -1, 0, 0]
dc = [0, 0, -1, 1]

def dfs(y, x):
    g[y][x] = 1
    cnt = 1
    for i in range(4):
        ny, nx = y + dr[i], x + dc[i]
        if 0 <= ny < r and 0 <= nx < c and g[ny][nx] == 0:
            cnt += dfs(ny, nx)
    return cnt

ans = []
for i in range(r):
    for j in range(c):
        if g[i][j] == 0:
            ans.append(dfs(i, j))

ans.sort()
print(len(ans))
print(*ans)
```

## 예제 8. 꺼진/켜진 덩어리 개수

```py
import sys
sys.setrecursionlimit(10**6)
input = sys.stdin.readline

h, w = map(int, input().split())
g = [list(map(int, input().split())) for _ in range(h)]

dr = [1, -1, 0, 0]
dc = [0, 0, -1, 1]

def dfs(r, c, t, v):
    v[r][c] = True
    for i in range(4):
        nr, nc = r + dr[i], c + dc[i]
        if 0 <= nr < h and 0 <= nc < w:
            if not v[nr][nc] and g[nr][nc] == t:
                dfs(nr, nc, t, v)

def solve(t):
    v = [[False] * w for _ in range(h)]
    cnt = 0
    for i in range(h):
        for j in range(w):
            if not v[i][j] and g[i][j] == t:
                dfs(i, j, t, v)
                cnt += 1
    return cnt

print(solve(0), solve(1))
```

## 정리: 격자 연결 요소 문제는 다 같은 틀

- 바뀌는 건 **이동 조건**과 **결과를 모으는 방법**
- 이동 조건: 땅이면(섬) / 같은 숫자면(애니팡) / 'L'이면(8방향)
- 결과 모으기: 개수만(+1) / 크기(count=1+이웃 return) / 조건 있는 개수(size>=3) / 종류별 최댓값(딕셔너리 max)
