# 1. 재귀

## 재귀란

- 함수가 자기 자신을 다시 호출하는 것
- 반드시 두 부분으로: base case(멈춤) / recursive case(한 단계 작은 같은 문제)
- base case가 없거나 도달 못 하면 `RecursionError`
- 파이썬 기본 재귀 깊이 제한 약 1000 → 깊어지면 `sys.setrecursionlimit(10**6)`

## 기본: 1부터 n까지의 합

```py
def s(x):
    if x == 1:          # base case
        return 1
    return x + s(x - 1) # recursive case

print(s(4))   # 4 + 3 + 2 + 1 = 10
```

- 함수 이름을 `sum`으로 쓰면 내장 `sum`을 덮어씀 → 다른 이름 사용

## 팰린드롬 판별

```py
def p(x):
    if len(x) <= 1:         # 0글자, 1글자는 항상 팰린드롬
        return True
    if x[0] != x[-1]:       # 양 끝이 다르면 탈락
        return False
    return p(x[1:-1])       # 양 끝 떼고 안쪽 재검사

s = input().strip()
print(p(s))
```

- 한 줄 버전: `return x == x[::-1]`

## 중첩 리스트의 합

```py
import json
data = json.loads(input())   # 예: [1, [2, 3], [[4]], 5]

def TOTAL(x):
    if isinstance(x, int):   # base case
        return x
    s = 0
    for i in x:
        s += TOTAL(i)
    return s

print(TOTAL(data))   # 15
```

## 중첩 리스트 펼치기 (평탄화)

```py
import json
data = json.loads(input())   # 예: [1, [2, [3, 4]], []]

def count(x):
    s = []
    for i in x:
        if isinstance(i, int):
            s.append(i)
        else:
            s += count(i)
    return s

if isinstance(data, int):
    print(data)
elif count(data):
    print(*count(data))      # 1 2 3 4
else:
    print("EMPTY")
```

## 괄호 깊이 (중첩 리스트의 최대 깊이)

### 방법 1: 반복문 + 카운터

```py
s = input()
k = 0       # 현재 깊이
mx = 0      # 최대 깊이
for c in s:
    if c == '[':
        k += 1
        mx = max(mx, k)
    elif c == ']':
        k -= 1

print(mx)
```

### 방법 2: 재귀

```py
import json
data = json.loads(input())

def d(x):
    if isinstance(x, int):   # 숫자는 깊이 0
        return 0
    k = 0
    for i in x:
        k = max(k, d(i))
    return k + 1             # 나 자신이 한 겹 추가

print(d(data))
```

## 계단 오르기 (재귀 → 메모이제이션 → DP)

- 규칙: 1칸 또는 2칸, 연속 3칸 금지, 마지막 계단 필수. 최대 점수
- 점화식: `best(i) = max(best(i-2)+score[i], best(i-3)+score[i-1]+score[i])`

### 1단계: 점화식을 그대로 재귀로 (시간 초과)

```py
n = int(input())
score = [0]
for _ in range(n):
    score.append(int(input()))

def best(i):
    if i == 0:
        return 0
    if i == 1:
        return score[1]
    if i == 2:
        return score[1] + score[2]
    return max(best(i - 2) + score[i],
               best(i - 3) + score[i - 1] + score[i])

print(best(n))
```

### 2단계: 메모이제이션 (탑다운 DP, O(n))

```py
n = int(input())
score = [0]
for _ in range(n):
    score.append(int(input()))

memo = [-1] * (n + 1)

def best(i):
    if i == 0:
        return 0
    if i == 1:
        return score[1]
    if i == 2:
        return score[1] + score[2]
    if memo[i] != -1:
        return memo[i]
    memo[i] = max(best(i - 2) + score[i],
                  best(i - 3) + score[i - 1] + score[i])
    return memo[i]

print(best(n))
```

### 추가 풀이: DP (바텀업)

```py
n = int(input())
score = [0]
for _ in range(n):
    score.append(int(input()))

best = [0] * (n + 1)
best[1] = score[1]
if n >= 2:
    best[2] = score[1] + score[2]

for i in range(3, n + 1):
    best[i] = max(best[i - 2] + score[i],
                  best[i - 3] + score[i - 1] + score[i])

print(best[n])
```

# 2. 백트래킹

## 백트래킹이란

- 가능한 선택을 하나씩 해보고, 안 되면 직전 선택을 취소(되돌리기)하고 다른 선택
- 틀: ① base case ② 후보 하나씩 ③ 조건 검사 ④ 선택(append) ⑤ 재귀 ⑥ 되돌리기(pop)

## 기본 코드: 0과 1로 만드는 길이 n 수열

```py
n = int(input())
l = []

def b():
    if len(l) == n:     # base case
        print(*l)
        return

    for i in [0, 1]:
        l.append(i)     # 선택
        b()             # 탐색
        l.pop()         # 되돌리기

b()
```

## 순열: 1~n 중 m개 순서 있게

```py
n, m = map(int, input().split())
l = []

def f():
    if len(l) == m:
        print(*l)
        return
    for i in range(1, n + 1):
        if i not in l:
            l.append(i)
            f()
            l.pop()

f()
```

## 조합: 1~n 중 m개 순서 없이

```py
n, m = map(int, input().split())
l = []

def f(s):
    if len(l) == m:
        print(*l)
        return
    for i in range(s, n + 1):   # s부터 → 앞에서 고른 것보다 큰 수만
        l.append(i)
        f(i + 1)
        l.pop()

f(1)
```

## 가지치기 (합이 정확히 k)

```py
n, m, k = map(int, input().split())

def b(s, cnt, tot):
    if tot > k:             # 가지치기
        return 0
    if cnt == m:
        return 1 if tot == k else 0
    c = 0
    for i in range(s, n + 1):
        c += b(i + 1, cnt + 1, tot + i)
    return c

print(b(1, 0, 0))
```

- 리스트 대신 cnt, tot를 인자로 넘기면 append/pop 없이 되돌리기 자동

# 3. 예제들

## 예제 1. N Queen

- 배치한 퀸의 행/열을 리스트의 index/value로 해석

### 비효율 버전 (참고)

```py
n = int(input())
l = []

def b():
    if len(l) == n:
        return 1
    c = 0
    for r in range(n):
        if not can_place(r):
            continue
        l.append(r)
        c += b()
        l.pop()
    return c

def can_place(r):
    if r in l:
        return False
    for i in l:
        if abs(l.index(i) - len(l)) == abs(i - r):
            return False
    return True

print(b())
```

- 문제점: `can_place`가 O(N²), 전체 O(N! × N³)로 매우 느림

### 개선: 체크 배열로 O(1) 검사

- 우상향 대각선(/): 행+열 일정 → `vdd[curr_len + r]`
- 우하향 대각선(\\): 행−열 일정 → `vd[curr_len - r + n]` (음수 방지 +n)

```py
import sys
input = sys.stdin.readline

n = int(input())
l = []
s = 0

vc = [False] * n
vd = [False] * (2 * n)
vdd = [False] * (2 * n)

def b():
    global s
    curr_len = len(l)
    if curr_len == n:
        if s < 3:
            k = [i + 1 for i in l]
            s += 1
            print(*k)
        return 1
    
    c = 0
    for r in range(n):
        if not con(r, curr_len):
            continue
        l.append(r)
        vc[r] = True
        vd[curr_len - r + n] = True
        vdd[curr_len + r] = True
        c += b()

        l.pop()
        vc[r] = False
        vd[curr_len - r + n] = False
        vdd[curr_len + r] = False

    return c

def con(r, curr_len):
    if vc[r]:
        return False
    if vd[curr_len - r + n]:
        return False
    if vdd[curr_len + r]:
        return False
    return True

print(b())
```

## 예제 2. 회의실 배정

### 백트래킹

```py
n = int(input())
a = [tuple(map(int, input().split())) for _ in range(n)]
a.sort()    # 시작 시간 순

l = []
ans = 0

def b(i):
    global ans
    if i == n:
        ans = max(ans, len(l))
        return
    if len(l) + (n - i) <= ans:     # 가지치기
        return
    s, e = a[i]
    if not l or l[-1][1] <= s:      # 겹치지 않으면 넣기
        l.append(a[i])
        b(i + 1)
        l.pop()
    b(i + 1)                        # 안 넣는다

b(0)
print(ans)
```

### 그리디 (n이 클 때)

```py
n = int(input())
a = [tuple(map(int, input().split())) for _ in range(n)]
a.sort(key=lambda x: (x[1], x[0]))   # 끝나는 시간 순

t = 0
c = 0
for s, e in a:
    if t <= s:
        c += 1
        t = e

print(c)
```

## 예제 3. 스도쿠

### 개선 코드 (체크 배열 + 빈칸 목록)

```py
board = [list(map(int, input().split())) for _ in range(9)]

row_used = [[False] * 10 for _ in range(9)]
col_used = [[False] * 10 for _ in range(9)]
box_used = [[False] * 10 for _ in range(9)]
blanks = []

def box_id(r, c):
    return (r // 3) * 3 + c // 3

for r in range(9):
    for c in range(9):
        num = board[r][c]
        if num == 0:
            blanks.append((r, c))
        else:
            row_used[r][num] = True
            col_used[c][num] = True
            box_used[box_id(r, c)][num] = True

def solve(idx):
    if idx == len(blanks):
        return True
    r, c = blanks[idx]
    box = box_id(r, c)
    for num in range(1, 10):
        if row_used[r][num] or col_used[c][num] or box_used[box][num]:
            continue
        board[r][c] = num
        row_used[r][num] = col_used[c][num] = box_used[box][num] = True
        if solve(idx + 1):
            return True
        board[r][c] = 0
        row_used[r][num] = col_used[c][num] = box_used[box][num] = False
    return False

solve(0)
for row in board:
    print(*row)
```

### 3×3 박스 인덱싱

- 박스 번호 (0~8): `(r // 3) * 3 + c // 3`
- 박스 시작 칸: `((r // 3) * 3, (c // 3) * 3)`

### 패턴 정리

- "답 하나만 찾으면 끝": `if solve(...): return True`로 True를 위로 전달
- 경우의 수 세기(N Queen)는 `c += b()`로 더함, 답 하나(스도쿠)는 True를 바로 return
- 판(board)·체크 배열은 전역 → 되돌리기 필수. r/c/num/idx는 호출마다 따로 → 되돌릴 필요 없음
