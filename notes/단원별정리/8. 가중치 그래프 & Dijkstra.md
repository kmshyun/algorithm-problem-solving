# 1. 가중치 그래프

- 간선에 비용(가중치, 길이)이 붙은 그래프. 주로 방향 그래프
- 인접 리스트에 저장할 때 `(도착 정점, 가중치)` 튜플로 묶어서 저장

## 코드 (트리: 간선 n-1개)

```py
n = int(input())
g = [[] for _ in range(n + 1)]

for _ in range(n - 1):
    u, v, w = map(int, input().split())
    g[u].append((v, w))
    g[v].append((u, w))
```

## 일반 그래프 인접 리스트 (간선 m개, 출력 연습)

```py
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n + 1)]

for _ in range(m):
    u, v, w = map(int, input().split())
    adj[u].append((v, w))
    adj[v].append((u, w))

for i in range(1, n + 1):
    adj[i].sort(key=lambda x: x[0])
    output = [i, len(adj[i])]
    for neighbor, time in adj[i]:
        output.append(neighbor)
        output.append(time)
    print(*(output))
```

# 2. 다익스트라 (Dijkstra)

- 음의 가중치가 없는 그래프에서 한 출발점 → 모든 정점 최단 경로
- BFS가 가중치 1일 때라면, 다익스트라는 가중치가 다를 때
- 매 순간 "누적 거리가 가장 짧은 정점"을 꺼냄 → 우선순위 큐(heapq)

## heapq 핵심 규칙

- 튜플 `(a, b)`는 첫 원소 `a` 기준 비교 → 반드시 `(누적 거리, 노드 번호)` 순서
- 이미 처리된 노드 걸러내기:

```py
d, cur = heapq.heappop(pq)
if d > dist[cur]:   # 낡은 정보면 버림
    continue
```

- 주의: `d >= dist[cur]`로 등호 넣으면 시작 노드(d=0)부터 걸러져서 안 됨. 반드시 `>`

## heapq 연습 (우선순위 큐)

```py
import sys
import heapq

input = sys.stdin.readline
q = int(input())
heap = []
output = []

for _ in range(q):
    cmd = input().split()
    if cmd[0] == '1':
        id = int(cmd[1])
        p = int(cmd[2])
        heapq.heappush(heap, (p, id))
    else:
        if heap:
            p, id = heapq.heappop(heap)
            output.append(str(id))
        else:
            output.append("EMPTY")

sys.stdout.write("\n".join(output) + "\n")
```

## 기본 코드 (인접 리스트 + 힙큐)

```py
import sys
import heapq
input = sys.stdin.readline
INF = float('inf')

v, e = map(int, input().split())
g = [[] for _ in range(v + 1)]

for _ in range(e):
    u, v_node, w = map(int, input().split())
    g[u].append((v_node, w))
    g[v_node].append((u, w))

s, t = map(int, input().split())

dist = [INF] * (v + 1)
dist[s] = 0

pq = []
heapq.heappush(pq, (0, s))

while pq:
    d, cur = heapq.heappop(pq)
    if d > dist[cur]:
        continue
    for nxt, w in g[cur]:
        if d + w < dist[nxt]:
            dist[nxt] = d + w
            heapq.heappush(pq, (d + w, nxt))

ans = dist[t]
print(-1 if ans == INF else ans)
```

## 시간 복잡도 / 주의

- O(E log V)
- 음수 가중치 불가 (그리디 가정 깨짐) → 음수면 벨만-포드
- 튜플 순서 `(cost, node)` 필수
- 문자 정점은 dict로 `dist` 구성하거나 `ord(ch) - ord('A')`

# 3. 다익스트라의 활용

## 활용 ① 최단경로 (문자 정점 OK)

```py
import sys
import heapq
input = sys.stdin.readline
INF = float('inf')

v, e = map(int, input().split())
g = {}

for _ in range(e):
    u, v_node, w = input().split()
    w = int(w)
    g.setdefault(u, []).append((v_node, w))
    g.setdefault(v_node, []).append((u, w))

s, t = input().split()

dist = {node: INF for node in g}
dist[s] = 0

pq = []
heapq.heappush(pq, (0, s))

while pq:
    d, cur = heapq.heappop(pq)
    if d > dist[cur]:
        continue
    for i, w in g[cur]:
        if d + w < dist[i]:
            dist[i] = d + w
            heapq.heappush(pq, (d+w, i))

ans = dist.get(t, INF)
print(-1 if ans == INF else ans)
```

## 활용 ② 최단경로 복원 (prev 딕셔너리)

```py
import heapq
import sys
input = sys.stdin.readline
INF = float('inf')

v, e = map(int, input().split())
g = {}

for _ in range(e):
    u, v_node, w = input().split()
    w = int(w)
    g.setdefault(u, []).append((v_node, w))
    g.setdefault(v_node, []).append((u, w))

s, t = input().split()

dist = {node: INF for node in g}
dist[s] = 0
prev = {node: None for node in g}

pq = []
heapq.heappush(pq, (0, s))

while pq:
    d, cur = heapq.heappop(pq)
    if d > dist[cur]:
        continue
    for nxt, weight in g.get(cur, []):
        cost = d + weight
        if cost < dist.get(nxt, INF):
            dist[nxt] = cost
            prev[nxt] = cur
            heapq.heappush(pq, (cost, nxt))

ans = dist.get(t, INF)

if ans == INF:
    print(-1)
else:
    path = []
    curr_node = t
    while curr_node is not None:
        path.append(curr_node)
        curr_node = prev.get(curr_node)
    path.reverse()
    print(ans)
    for i in path:
        print(i)
```

## 예제 3. 경유지 (s → k → t), 무방향

```py
import sys
import heapq
input = sys.stdin.readline
INF = float('inf')

v, e = map(int, input().split())
s, k, t = map(int, input().split())
g = [[] for _ in range(v + 1)]

for _ in range(e):
    u, v_node, w = map(int, input().split())
    g[u].append((v_node, w))
    g[v_node].append((u, w))

def dj(st):
    dist = [INF] * (v + 1)
    dist[st] = 0
    pq = []
    heapq.heappush(pq, (0, st))
    while pq:
        d, cur = heapq.heappop(pq)
        if d > dist[cur]:
            continue
        for nxt, w in g[cur]:
            if d + w < dist[nxt]:
                dist[nxt] = d + w
                heapq.heappush(pq, (d + w, nxt))
    return dist

distance = dj(s)[k] + dj(k)[t]
print(distance if distance != INF else -1)
```

## 예제 4. 왕복 가능한 정점 개수 (간선 뒤집기 최적화)

```py
import sys
import heapq
input = sys.stdin.readline
INF = float('inf')

v, e = map(int, input().split())
s, t = map(int, input().split())
g = [[] for _ in range(v + 1)]
rg = [[] for _ in range(v + 1)]

for _ in range(e):
    u, v_node, w = map(int, input().split())
    g[u].append((v_node, w))
    rg[v_node].append((u, w))   # 간선 뒤집은 그래프

def dj(st, gr):
    dist = [INF] * (v + 1)
    dist[st] = 0
    pq = []
    heapq.heappush(pq, (0, st))
    while pq:
        d, cur = heapq.heappop(pq)
        if d > dist[cur]:
            continue
        for nxt, w in gr[cur]:
            if d + w < dist[nxt]:
                dist[nxt] = d + w
                heapq.heappush(pq, (d + w, nxt))
    return dist

go = dj(s, g)       # s → k
back = dj(s, rg)    # k → s (뒤집은 그래프에서 s → k)

times = 0
for k in range(1, v + 1):
    if k != s and go[k] + back[k] <= t:
        times += 1

print(times)
```

- 다익스트라 횟수: 순진한 풀이 2v번 → 간선 뒤집기로 2번

## 예제 5. 격자에서의 최소 비용 경로

```py
import sys
import heapq

input = sys.stdin.readline

n, m = map(int, input().split())
g = []
for _ in range(n):
    g.append(input().split())

INF = float('inf')
dist = [[INF] * m for _ in range(n)]
dist[0][0] = 0

dr = [-1,1,0,0]
dc = [0,0,-1,1]

pq = []
heapq.heappush(pq, (0,(0,0)))

while pq:
    time, cor = heapq.heappop(pq)
    r, c = cor
    if time > dist[r][c]:
        continue
    for i in range(4):
        nr = r + dr[i]
        nc = c + dc[i]
        if 0 <= nr < n and 0 <= nc < m:
            if time + int(g[nr][nc]) < dist[nr][nc]:
                dist[nr][nc] = time + int(g[nr][nc])
                heapq.heappush(pq, (time + int(g[nr][nc]), (nr, nc)))

print(dist[n-1][m-1])
```
