# 1. Prefix Sum (누적합)

## 누적합이란

- 배열의 앞에서부터 합을 미리 쌓아둔 배열 s를 만들어두는 것
- s[i] = l[0] + l[1] + … + l[i-1] → "s[i]는 앞에서부터 i개의 합", s[0] = 0
- a번째 ~ b번째(1번부터 셈) 구간의 합 = s[b] - s[a-1]
- 매번 `sum(l[a-1:b])`를 하면 질문 하나에 O(n) → 질문 k개면 O(nk)
- 누적합은 만들 때 O(n) 한 번, 질문 하나에 O(1) → 전체 O(n + k)
- s를 n+1칸으로 잡고 s[0] = 0을 두는 이유: a = 1일 때 s[a-1] = s[0] = 0이 되어서 예외 처리 불필요

## 기본 코드

```py
n = int(input())
l = list(map(int, input().split()))

s = [0] * (n + 1)
for i in range(1, n + 1):
    s[i] = s[i-1] + l[i-1]   # s는 1번부터, l은 0번부터 → i-1 주의

a, b = map(int, input().split())
print(s[b] - s[a-1])          # a번째 ~ b번째 합
```

- 예: l = [3, 1, 4, 1, 5] → s = [0, 3, 4, 8, 9, 14]
- 2~4번째 합 = s[4] - s[1] = 9 - 3 = 6 (= 1 + 4 + 1)
- 인덱스 헷갈림 1순위: s는 l보다 한 칸 밀려 있음 → "s[i]는 앞에서 i개"로 외우기

## 2차원 누적합 (작년 기출!)

- `s[i][j]` = (1, 1)부터 (i, j)까지 직사각형 안의 합
- s를 (n+1) × (m+1)로 잡고 0번 행/열은 전부 0

### 식 ① 누적합 배열 만들기: 위 + 왼 - 대각 + 나

`s[i][j] = s[i-1][j] + s[i][j-1] - s[i-1][j-1] + A[i][j]`

- `s[i-1][j]` (위쪽 직사각형 전부) + `s[i][j-1]` (왼쪽 직사각형 전부) - `s[i-1][j-1]` (겹친 부분 한 번 빼기) + `A[i][j]` (현재 칸)

### 식 ② 직사각형 합 구하기: 전체 - 위 - 왼 + 대각

`(x1, y1) ~ (x2, y2) 합 = s[x2][y2] - s[x1-1][y2] - s[x2][y1-1] + s[x1-1][y1-1]`

- 두 식 모두 "포함-배제": 두 번 더해졌으면 한 번 빼고, 두 번 빠졌으면 한 번 더함
- 외우는 법 — 만들 때: 위 + 왼 - 대각 + 나 / 구할 때: 전체 - 위 - 왼 + 대각
- `-1`은 항상 시작 좌표 (x1, y1)에만, 끝 좌표 (x2, y2)에는 절대 안 붙음

### 기본 코드

```py
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
l = [list(map(int, input().split())) for _ in range(n)]

s = [[0] * (m + 1) for _ in range(n + 1)]   # (n+1) × (m+1), 0번 행/열은 0
for i in range(1, n + 1):
    for j in range(1, m + 1):
        s[i][j] = s[i-1][j] + s[i][j-1] - s[i-1][j-1] + l[i-1][j-1]

k = int(input())
for _ in range(k):
    x1, y1, x2, y2 = map(int, input().split())   # 1번부터 센 좌표
    print(s[x2][y2] - s[x1-1][y2] - s[x2][y1-1] + s[x1-1][y1-1])
```

### 예시로 확인

```txt
l =  1 2 3        s =  0  0  0  0
     4 5 6             0  1  3  6
     7 8 9             0  5 12 21
                       0 12 27 45
```

- 만들기: `s[2][2]` = 3 + 5 - 1 + 5 = 12 (= 1 + 2 + 4 + 5) ✔
- 구하기: (2, 2)~(3, 3) 합 = 45 - 6 - 12 + 1 = 28 (= 5 + 6 + 8 + 9) ✔

### 손코딩 인덱스 체크리스트

- s는 `[[0] * (m + 1) for _ in range(n + 1)]` (바깥=행 n+1개, 안쪽=열 m+1개)
- `[[0] * (m + 1)] * (n + 1)` 금지 → 모든 행이 같은 리스트 하나를 가리킴
- 만들 때 l은 `l[i-1][j-1]` (s만 한 칸씩 밀려 있음)
- 질문 좌표가 0번부터면 입력 받자마자 +1

# 2. Two Pointer (투 포인터)

## 투 포인터란

- 인덱스 두 개(left, right)를 움직이면서 답을 찾는 방법. O(n²) → O(n)
- 양 끝에서 안쪽으로 (정렬된 배열) / 둘 다 왼→오 (길이 정해지지 않은 구간)
- 전제: 정렬되어 있거나 값이 전부 양수

## 기본 코드: 정렬된 배열에서 합이 k인 두 수

```py
n, k = map(int, input().split())
l = list(map(int, input().split()))   # 오름차순

left = 0
right = n - 1
while left < right:
    s = l[left] + l[right]
    if s == k:
        break
    elif s < k:       # 더 큰 수 필요 → left 오른쪽으로
        left += 1
    else:             # 더 작은 수 필요 → right 왼쪽으로
        right -= 1

print(left + 1, right + 1)
```

- `left < right` (≤ 아님): 같은 원소를 두 번 쓰면 안 되니까

## 참고: 같은 방향 투 포인터 (합이 k 이상인 가장 짧은 연속 구간)

```py
n, k = map(int, input().split())
l = list(map(int, input().split()))

left = 0
cur = 0
ans = n + 1
for right in range(n):
    cur += l[right]
    while cur >= k:
        ans = min(ans, right - left + 1)
        cur -= l[left]
        left += 1

print(ans if ans <= n else 0)
```

# 3. Sliding Window (슬라이딩 윈도우)

## 슬라이딩 윈도우란

- 길이가 k로 고정된 "창문"을 한 칸씩 밀면서 합·개수를 갱신
- 한 칸 밀 때: 왼쪽에서 하나 빠지고 오른쪽에서 하나 들어옴 → O(1) → 전체 O(n)

## 기본 코드: 길이 k 구간 합의 최댓값

```py
n, k = map(int, input().split())
l = list(map(int, input().split()))

cur = sum(l[:k])      # 첫 창문 [0, k-1]
best = cur
m = 0
for j in range(1, n - k + 1):          # j = 새 창문의 시작
    cur = cur - l[j-1] + l[j+k-1]      # 빠지는 l[j-1], 들어오는 l[j+k-1]
    if cur > best:
        best = cur
        m = j

print(m + 1, best)
```

# 4. 세 기법 비교 / 언제 뭘 쓰나

- 공통점: O(n²)/O(nk)를 O(n) 근처로 줄임
- Prefix Sum: 위치 제각각 구간 질문 여러 개. 음수 OK
- Sliding Window: 구간 길이가 k로 고정
- Two Pointer: 두 원소 쌍 찾기 / 구간 길이 정해지지 않음. 정렬 또는 양수 조건
- 문제 읽고 판단: "a~b 질문 여러 번" → 누적합 / "연속한 k개" → 슬라이딩 / "두 수 합 k, 가장 짧은/긴 구간" → 투 포인터

# 5. 예제들

## 예제 1. 구간 합 구하기 (Prefix Sum)

```py
n, k = map(int, input().split())
l = list(map(int, input().split()))
s = [0] * (n+1)
for i in range(1, n+1):
    s[i] = s[i-1] + l[i-1]

for j in range(k):
    a, b = map(int, input().split())
    print(s[b] - s[a-1])
```

## 예제 2. 구간 안에서 r 이상인 수의 개수 (Prefix Sum + 0/1 변환)

```py
n, k, r = map(int, input().split())
l = list(map(int, input().split()))
s = []
for i in l:
    if i >= r:
        s.append(1)
    else:
        s.append(0)

ss = [0] * (n+1)
for i in range(1, n+1):
    ss[i] = ss[i-1] + s[i-1]

for j in range(k):
    a, b = map(int, input().split())
    print(ss[b] - ss[a-1])
```

## 예제 3. 길이 k 구간 합의 최댓값

### 방법 1: 누적합

```py
n, k = map(int, input().split())
l = list(map(int, input().split()))
s = [0] * (n+1)

for i in range(1, n+1):
    s[i] = s[i-1] + l[i-1]

r = s[k]
d = 0
for j in range(n-k+1):
    c = s[j+k] - s[j]
    if c > r:
        r = c
        d = j
        
print(d+1, r)
```

## 예제 7. 길이 k 구간에서 서로 다른 값이 가장 많은 구간

### set 방식

```py
n, k = map(int, input().split())
l = input().split()

cur = l[:k]
best = len(set(cur))
m = 0
for i in range(1, n - k + 1):
    cur.append(l[i+k-1])
    cur.remove(l[i-1])
    if len(set(cur)) > best:
        best = len(set(cur))
        m = i

print(m + 1, best)
```

- 주의: `best = cur`로 두면 리스트 참조 공유 버그 → 종류 수(숫자)를 저장해야 함

### 딕셔너리(해싱)로 O(n)

```py
n, k = map(int, input().split())
l = input().split()

d = {}                     # 값: 창문 안 개수
for x in l[:k]:
    d[x] = d.get(x, 0) + 1

best = len(d)
m = 0
for i in range(1, n - k + 1):
    x = l[i-1]             # 빠지는 값
    d[x] -= 1
    if d[x] == 0:
        del d[x]
    y = l[i+k-1]           # 들어오는 값
    d[y] = d.get(y, 0) + 1
    if len(d) > best:
        best = len(d)
        m = i

print(m + 1, best)
```

## 예제 8. 정렬된 배열에서 합이 k인 두 수 (Two Pointer)

```py
n, k = map(int, input().split())
l = list(map(int, input().split()))
left = 0
right = n-1
while left < right:
    s = l[left] + l[right]
    if s < k:
        left += 1
    elif s > k:
        right -= 1
    elif s == k:
        break

print(left+1, right+1)
```
