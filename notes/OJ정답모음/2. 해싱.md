## 문제 1. 등록된 실험 샘플 확인 (활용 ① 존재 여부)

- 등록 샘플 n개, 질문 m개. 질문마다 등록됐으면 YES, 아니면 NO. O(n + m)

```py
n, m = map(int, input().split())
registered = set(input().split())
queries = input().split()

for sample_id in queries:
    if sample_id in registered:
        print("YES")
    else:
        print("NO")
```

## 문제 2. 서로 다른 센서는 몇 개인가? (활용 ② 중복 제거)

```py
n = int(input())
sensor_ids = input().split()
print(len(set(sensor_ids)))
```

## 문제 3. 미등록 실험 샘플 찾기 (활용 ③ 차집합, 순서 유지)

```py
n, m = map(int, input().split())
registered = set(input().split())
observed = input().split()

unregistered = []
for sample_id in observed:
    if sample_id not in registered:
        unregistered.append(sample_id)

if unregistered:
    print(*unregistered)
else:
    print("NONE")
```

## 문제 4. 가장 경고가 많았던 교실 (활용 ④ 빈도수와 최빈값)

- 동률이면 로그에 먼저 나온 교실. O(n)

```py
n = int(input())
logs = input().split()

count = {}
for room in logs:
    count[room] = count.get(room, 0) + 1

best_room = logs[0]
best_count = count[best_room]
for room in logs:
    if count[room] > best_count:
        best_room = room
        best_count = count[room]

print(best_room, best_count)
```

## 문제 5. 샘플별 측정 횟수 (활용 ⑤ 개수 질문)

- 미리 dict로 세고 `get(x, 0)`. O(n + q) (질문마다 `count()`면 O(n×q) 시간 초과)

```py
n = int(input())
samples = input().split()

count = {}
for sample in samples:
    count[sample] = count.get(sample, 0) + 1

q = int(input())
queries = input().split()
for sample in queries:
    print(count.get(sample, 0))
```

## 문제 6. 등록 센서의 경고 통계 (활용 ⑥ set + dict)

- 등록 센서 경고만 세서 최다 센서. 동률이면 먼저. 없으면 `NONE 0`. O(n + m)

```py
n, m = map(int, input().split())
registered = set(input().split())
logs = input().split()

count = {}
for sensor in logs:
    if sensor in registered:
        count[sensor] = count.get(sensor, 0) + 1

best_sensor = None
best_count = 0
for sensor in logs:
    if sensor in registered and count[sensor] > best_count:
        best_sensor = sensor
        best_count = count[sensor]

if best_sensor is None:
    print("NONE", 0)
else:
    print(best_sensor, best_count)
```
