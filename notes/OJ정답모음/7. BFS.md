> 공통: `dist = [-1] * (N + 1)`이 visited 역할(-1 = 아직 안 옴). 큐에 넣을 때 바로 거리 기록. BFS 한 번 O(N + M).

## 문제 1. 실험동 최소 이동

```py
import sys
from collections import deque
input = sys.stdin.readline

N, M = map(int, input().split())
graph = [[] for _ in range(N + 1)]
for _ in range(M):
    u, v = map(int, input().split())
    graph[u].append(v)
    graph[v].append(u)
S, T = map(int, input().split())

dist = [-1] * (N + 1)
dist[S] = 0
queue = deque([S])

while queue:
    cur = queue.popleft()
    if cur == T:
        break
    for nxt in graph[cur]:
        if dist[nxt] != -1:
            continue
        dist[nxt] = dist[cur] + 1
        queue.append(nxt)

print(dist[T])
```

## 문제 3. 가장 가까운 비상구

- 비상구 번호를 set에. 처음 꺼낸 비상구가 가장 가까움 → 바로 종료 (비상구마다 BFS 돌리면 O(K(N+M)))

```py
import sys
from collections import deque
input = sys.stdin.readline

N, M = map(int, input().split())
graph = [[] for _ in range(N + 1)]
for _ in range(M):
    u, v = map(int, input().split())
    graph[u].append(v)
    graph[v].append(u)
S, K = map(int, input().split())
exits = set(map(int, input().split()))

dist = [-1] * (N + 1)
dist[S] = 0
queue = deque([S])
answer = -1

while queue:
    cur = queue.popleft()
    if cur in exits:
        answer = dist[cur]
        break
    for nxt in graph[cur]:
        if dist[nxt] != -1:
            continue
        dist[nxt] = dist[cur] + 1
        queue.append(nxt)

print(answer)
```

## 문제 4. 정확히 K단계 떨어진 연구실

- 입력 순서가 `N M K S` (K가 S보다 앞) — 주의

```py
import sys
from collections import deque
input = sys.stdin.readline

N, M, K, S = map(int, input().split())
graph = [[] for _ in range(N + 1)]
for _ in range(M):
    u, v = map(int, input().split())
    graph[u].append(v)
    graph[v].append(u)

dist = [-1] * (N + 1)
dist[S] = 0
queue = deque([S])

while queue:
    cur = queue.popleft()
    for nxt in graph[cur]:
        if dist[nxt] != -1:
            continue
        dist[nxt] = dist[cur] + 1
        queue.append(nxt)

answer = []
for room in range(1, N + 1):
    if dist[room] == K:
        answer.append(room)

if answer:
    print(*answer)
else:
    print(-1)
```

## 문제 5. 연구동 최단 경로 복원

```py
import sys
from collections import deque
input = sys.stdin.readline

N, M = map(int, input().split())
graph = [[] for _ in range(N + 1)]
for _ in range(M):
    u, v = map(int, input().split())
    graph[u].append(v)
    graph[v].append(u)
S, T = map(int, input().split())

dist = [-1] * (N + 1)
parent = [-1] * (N + 1)
dist[S] = 0
queue = deque([S])

while queue:
    cur = queue.popleft()
    if cur == T:
        break
    for nxt in graph[cur]:
        if dist[nxt] != -1:
            continue
        dist[nxt] = dist[cur] + 1
        parent[nxt] = cur
        queue.append(nxt)

path = []
node = T
while node != -1:
    path.append(node)
    node = parent[node]
path.reverse()

print(dist[T])
print(*path)
```

## 문제 6. 실험실 미로 탈출 (격자 BFS)

- `0` = 길, `1` = 벽. 좌표는 1부터. 범위 검사를 `maze[nr][nc]`보다 먼저!

```py
import sys
from collections import deque
input = sys.stdin.readline

N, M = map(int, input().split())
maze = [input().strip() for _ in range(N)]
start_r, start_c, goal_r, goal_c = map(int, input().split())
start_r, start_c, goal_r, goal_c = start_r - 1, start_c - 1, goal_r - 1, goal_c - 1

dist = [[-1] * M for _ in range(N)]
dist[start_r][start_c] = 0
queue = deque([(start_r, start_c)])

while queue:
    r, c = queue.popleft()
    if r == goal_r and c == goal_c:
        break
    for nr, nc in [(r - 1, c), (r + 1, c), (r, c - 1), (r, c + 1)]:
        if 0 <= nr < N and 0 <= nc < M and maze[nr][nc] == "0" and dist[nr][nc] == -1:
            dist[nr][nc] = dist[r][c] + 1
            queue.append((nr, nc))

print(dist[goal_r][goal_c])
```

## 문제 7. 순간이동 장치 (상태 BFS)

```py
import sys
from collections import deque
input = sys.stdin.readline

S, T = map(int, input().split())
LIMIT = 100_000

dist = [-1] * (LIMIT + 1)
dist[S] = 0
queue = deque([S])

while queue:
    cur = queue.popleft()
    if cur == T:
        break
    for nxt in (cur - 1, cur + 1, cur * 2):
        if not (0 <= nxt <= LIMIT):
            continue
        if dist[nxt] != -1:
            continue
        dist[nxt] = dist[cur] + 1
        queue.append(nxt)

print(dist[T])
```

## 문제 8. 가장 짧은 점검 경로 (알파벳 정점, 사전순 최단)

- "알파벳 순서로 방문 / 사전순"이 보이면 `sort()`부터. 이웃 리스트 `g[i].sort()` 필수

```py
from collections import deque
import sys

input = sys.stdin.readline
n, m = map(int, input().split())
nodes = sorted(input().split())

g = {i: [] for i in nodes}
visited = {i: False for i in nodes}

for _ in range(m):
    a, b = input().split()
    g[a].append(b)
    g[b].append(a)

for i in nodes:          # ★ 이웃을 알파벳 순으로
    g[i].sort()

s, t = input().split()

dist = {i: -1 for i in nodes}
p = {i: None for i in nodes}
q = deque([s])

visited[s] = True
dist[s] = 0

while q:
    cur = q.popleft()
    if cur == t:
        break
    for nxt in g[cur]:
        if not visited[nxt]:
            visited[nxt] = True
            dist[nxt] = dist[cur] + 1
            p[nxt] = cur
            q.append(nxt)

if not visited[t]:
    print(-1)
    print("NONE")
else:
    print(dist[t])
    path = []
    curr = t
    while curr is not None:
        path.append(curr)
        curr = p[curr]
    print(*path[::-1])
```
