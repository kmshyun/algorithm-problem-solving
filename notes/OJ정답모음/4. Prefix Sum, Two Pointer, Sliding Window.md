## 문제 1. 실험 로그 구간 조회 (Prefix Sum)

```py
import sys
input = sys.stdin.readline

N, Q = map(int, input().split())
vibrations = list(map(int, input().split()))

prefix = [0] * (N + 1)
for i in range(1, N + 1):
    prefix[i] = prefix[i - 1] + vibrations[i - 1]

for _ in range(Q):
    L, R = map(int, input().split())
    print(prefix[R] - prefix[L - 1])
```

## 문제 2. 집중 진동 구간 (Sliding Window 최댓값)

```py
import sys
input = sys.stdin.readline

N, K = map(int, input().split())
vibrations = list(map(int, input().split()))

window_sum = sum(vibrations[:K])
best_sum = window_sum
best_start = 0

for right in range(K, N):
    window_sum += vibrations[right]
    window_sum -= vibrations[right - K]
    start = right - K + 1
    if window_sum > best_sum:
        best_sum = window_sum
        best_start = start

print(best_start + 1, best_sum)
```

## 문제 3. 목표 보정값 찾기 (Two Pointer)

```py
import sys
input = sys.stdin.readline

N, T = map(int, input().split())
values = list(map(int, input().split()))

left = 0
right = N - 1
while left < right:
    pair_sum = values[left] + values[right]
    if pair_sum == T:
        print(left + 1, right + 1)
        break
    elif pair_sum < T:
        left += 1
    else:
        right -= 1
```

## 문제 4. 경고 발생 횟수 조회 (Prefix Sum + 0/1)

```py
import sys
input = sys.stdin.readline

N, Q, T = map(int, input().split())
readings = list(map(int, input().split()))

prefix = [0] * (N + 1)
for i in range(1, N + 1):
    is_warning = 1 if readings[i - 1] >= T else 0
    prefix[i] = prefix[i - 1] + is_warning

for _ in range(Q):
    L, R = map(int, input().split())
    print(prefix[R] - prefix[L - 1])
```

## 문제 6. K분 동안 경고가 가장 많은 구간 (Sliding Window + 0/1)

```py
input = sys.stdin.readline

N, K, T = map(int, input().split())

is_warning = [1 if value >= T else 0 for value in readings]

window_count = sum(is_warning[:K])
best_count = window_count
best_start = 0

    window_count += is_warning[right]
    window_count -= is_warning[right - K]

        best_count = window_count
        best_start = start

print(best_start + 1, best_count)
```

## 문제 7. 서로 다른 센서 상태가 가장 많은 K분 (Sliding Window + dict)

```py
import sys
input = sys.stdin.readline

N, K = map(int, input().split())
states = input().split()

freq = {}
for state in states[:K]:
    freq[state] = freq.get(state, 0) + 1

best_count = len(freq)
best_start = 0

for right in range(K, N):
    outgoing = states[right - K]
    freq[outgoing] -= 1
    if freq[outgoing] == 0:
        del freq[outgoing]

    incoming = states[right]
    freq[incoming] = freq.get(incoming, 0) + 1

    start = right - K + 1
    if len(freq) > best_count:
        best_count = len(freq)
        best_start = start

print(best_start + 1, best_count)
```

## 문제 8. 목표값에 가장 가까운 두 값 (Two Pointer)

```py
import sys
input = sys.stdin.readline

N, T = map(int, input().split())
values = list(map(int, input().split()))

left = 0
right = N - 1
best_diff = float("inf")
best_left = 0
best_right = N - 1

while left < right:
    pair_sum = values[left] + values[right]
    diff = abs(pair_sum - T)
    if diff < best_diff:
        best_diff = diff
        best_left = left
        best_right = right
    if pair_sum < T:
        left += 1
    elif pair_sum > T:
        right -= 1
    else:
        break

print(best_left + 1, best_right + 1)
```

## 문제 9. 합이 T 이하인 쌍의 개수 (Two Pointer)

```py
import sys
input = sys.stdin.readline

N, T = map(int, input().split())
values = list(map(int, input().split()))

left = 0
right = N - 1
pair_count = 0

while left < right:
    if values[left] + values[right] <= T:
        pair_count += right - left
        left += 1
    else:
        right -= 1

print(pair_count)
```

## 문제 10. 연구실 데이터 분석 요청 (Sliding Window, K=30)

```py
import sys
input = sys.stdin.readline

N = int(input())
counts = list(map(int, input().split()))
K = 30

window_sum = sum(counts[:K])
best_sum = window_sum
best_start = 0

for right in range(K, N):
    window_sum += counts[right]
    window_sum -= counts[right - K]
    start = right - K + 1
    if window_sum > best_sum:
        best_sum = window_sum
        best_start = start

print(best_start + 1, best_sum)
```
