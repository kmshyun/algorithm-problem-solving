## 문제 1. 최근 실험 기록 되돌리기 (활용 ① 되돌리기, 스택)

```py
import sys
input = sys.stdin.readline

N = int(input())
history = []

for _ in range(N):
    command = input().split()
    if command[0] == "DO":
        history.append(command[1])
    else:                       # UNDO
        if history:
            print(history.pop())
        else:
            print("EMPTY")
```

## 문제 2. 잘못 닫힌 실험식 (활용 ② 괄호 검사, 한 종류)

```py
import sys
expr = sys.stdin.readline().strip()

stack = []
valid = True

for ch in expr:
    if ch == "(":
        stack.append(ch)
    else:                       # ')'
        if not stack:
            valid = False
            break
        stack.pop()

if stack:
    valid = False

print("YES" if valid else "NO")
```

## 문제 3. 코드 편집기의 실행 취소 (활용 ③ 텍스트 편집기)

```py
import sys
input = sys.stdin.readline

N = int(input())
typed = []

for _ in range(N):
    command = input().split()
    if command[0] == "TYPE":
        typed.append(command[1])
    else:                       # UNDO
        if typed:
            typed.pop()

if typed:
    print("".join(typed))
else:
    print("EMPTY")
```

## 문제 4. 세 종류의 괄호 검사 (활용 ② 여러 종류)

```py
import sys
expr = sys.stdin.readline().strip()

stack = []
pair = {")": "(", "]": "[", "}": "{"}
valid = True

for ch in expr:
    if ch in "([{":
        stack.append(ch)
    else:
        if not stack:                   # 경우 1
            valid = False
            break
        if stack[-1] != pair[ch]:       # 경우 2
            valid = False
            break
        stack.pop()

if stack:                               # 경우 3
    valid = False

print("YES" if valid else "NO")
```

## 문제 5. 충돌하는 센서 신호 (활용 ④ 인접 같은 문자 연쇄 제거)

```py
import sys
signal = sys.stdin.readline().strip()

stack = []
for ch in signal:
    if stack and stack[-1] == ch:
        stack.pop()
    else:
        stack.append(ch)

if stack:
    print("".join(stack))
else:
    print("EMPTY")
```

## 문제 6. 먼저 온 요청부터 처리 (큐 기본)

```py
from collections import deque
import sys
input = sys.stdin.readline

n = int(input())
requests = input().split()

queue = deque()
for request in requests:
    queue.append(request)

while queue:
    print(queue.popleft())
```

## 문제 7. 실험 장비 사용 대기열 (활용 ⑤ 대기열 호출)

```py
from collections import deque
import sys
input = sys.stdin.readline

q = int(input())
queue = deque()
output = []

for _ in range(q):
    command = input().split()
    if command[0] == "ENTER":
        queue.append(command[1])
    elif command[0] == "PROCESS":
        if queue:
            output.append(queue.popleft())
        else:
            output.append("EMPTY")

print("\n".join(output))
```

## 문제 9. 양쪽 샘플 보관함 (데크 기본 연산 4개)

```py
from collections import deque
import sys
input = sys.stdin.readline

q = int(input())
box = deque()
output = []

for _ in range(q):
    command = input().split()
    if command[0] == "ADD_LEFT":
        box.appendleft(command[1])
    elif command[0] == "ADD_RIGHT":
        box.append(command[1])
    elif command[0] == "REMOVE_LEFT":
        output.append(box.popleft() if box else "EMPTY")
    elif command[0] == "REMOVE_RIGHT":
        output.append(box.pop() if box else "EMPTY")

print("\n".join(output))
```

## 문제 10. 회전하는 샘플 트레이 (활용 ⑦ 원형 회전)

```py
from collections import deque
import sys
input = sys.stdin.readline

n, q = map(int, input().split())
tray = deque(input().split())
output = []

for _ in range(q):
    command = input().strip()
    if command == "LEFT":
        if tray:
            tray.append(tray.popleft())     # tray.rotate(-1)
    elif command == "RIGHT":
        if tray:
            tray.appendleft(tray.pop())     # tray.rotate(1)
    elif command == "ANALYZE":
        output.append(tray.popleft() if tray else "EMPTY")

print("\n".join(output))
```
