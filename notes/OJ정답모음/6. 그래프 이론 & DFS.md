> 공통: 정점 1~N번, 간선 M개. 인접 리스트 `graph[u]`. `cur`=지금 구역, `nxt`=다음. DFS 한 번 O(N + M). 재귀라 N 크면 `sys.setrecursionlimit(10**6)`

## 문제 1. 실험동 통로 정리

```py
N, M = map(int, input().split())
graph = [[] for _ in range(N + 1)]

for _ in range(M):
    u, v = map(int, input().split())
    graph[u].append(v)
    graph[v].append(u)

for room in range(1, N + 1):
    graph[room].sort()

for room in range(1, N + 1):
    print(f"{room}:", *graph[room])
```

## 문제 3. 안전구역에 도달할 수 있을까? (도달 여부)

```py
N, M, S, T = map(int, input().split())
graph = [[] for _ in range(N + 1)]

for _ in range(M):
    u, v = map(int, input().split())
    graph[u].append(v)
    graph[v].append(u)

visited = [False] * (N + 1)

def dfs(cur):
    visited[cur] = True
    for nxt in graph[cur]:
        if not visited[nxt]:
            dfs(nxt)

dfs(S)
print("YES" if visited[T] else "NO")
```

## 문제 8. 비상 탈출 경로 추적 (DFS 경로 복원)

- 이웃은 번호 작은 것부터. DFS 경로는 최단이 아님(최단은 BFS). 없으면 `NO PATH`

```py
N, M, S, T = map(int, input().split())
graph = [[] for _ in range(N + 1)]

for _ in range(M):
    u, v = map(int, input().split())
    graph[u].append(v)
    graph[v].append(u)

for room in range(1, N + 1):
    graph[room].sort()

visited = [False] * (N + 1)
path = []

def dfs(cur):
    visited[cur] = True
    path.append(cur)
    if cur == T:
        return True
    for nxt in graph[cur]:
        if not visited[nxt]:
            if dfs(nxt):
                return True
    path.pop()                      # 막다른 길
    return False

if dfs(S):
    print(len(path))
    print(*path)
else:
    print("NO PATH")
```
