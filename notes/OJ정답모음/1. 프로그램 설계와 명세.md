## 문제 1. 교실 CO₂ 모니터링 (종합)

- 평균/최댓값/최댓값 시각(처음)/1000 이상 횟수/1000 이상 시각 목록/환기 필요 여부 출력
- 환기 필요: 1000 이상이 3번 이상이거나 1300 이상이 한 번이라도 있으면 True
- O(n)

```py
n = int(input())
co2 = list(map(int, input().split()))

WARNING = 1000    # 경고 기준
DANGER = 1300     # 위험 기준

total = 0
warning_count = 0
warning_times = []
max_value = co2[0]
max_idx = 0
danger_found = False

for idx in range(n):
    value = co2[idx]
    total += value

    if value >= WARNING:
        warning_count += 1
        minutes = 13 * 60 + idx * 5
        warning_times.append(f"{minutes // 60:02d}:{minutes % 60:02d}")

    if value >= DANGER:
        danger_found = True

    if value > max_value:          # > 이므로 같은 값이면 처음 위치 유지
        max_value = value
        max_idx = idx

average = total / n

max_minutes = 13 * 60 + max_idx * 5
max_time = f"{max_minutes // 60:02d}:{max_minutes % 60:02d}"

need_ventilation = warning_count >= 3 or danger_found

print(f"{average:.1f}")
print(max_value)
print(max_time)
print(warning_count)
if warning_count == 0:
    print("NONE")
else:
    print(*warning_times)
print(need_ventilation)
```

- 주의: 1차시 명세(최댓값은 마지막 시각, 경고는 1000~1300 미만)와 정답 코드가 다름 → 정답 기준은 "최댓값은 처음 시각", "1000 이상이면 1300 넘어도 경고로 셈"

## 문제 2. CO₂ 상태 요약

- 평균(소수 첫째 자리)과 1000 이상 측정 횟수. O(n)

```py
n = int(input())
co2 = list(map(int, input().split()))

total = 0
warning_count = 0
for value in co2:
    total += value
    if value >= 1000:
        warning_count += 1

print(f"{total / n:.1f}")
print(warning_count)
```

## 문제 3. 최고 CO₂ 농도는 언제?

- 최댓값과 처음 나온 시각(HH:MM). `>`로 비교해 동점이면 처음 위치 유지. O(n)

```py
n = int(input())
co2 = list(map(int, input().split()))

max_value = co2[0]
max_idx = 0
for idx in range(1, n):
    if co2[idx] > max_value:
        max_value = co2[idx]
        max_idx = idx

minutes = 13 * 60 + max_idx * 5
print(max_value)
print(f"{minutes // 60:02d}:{minutes % 60:02d}")
```

## 문제 4. 환기 경고 기록

- 1000 이상 시각 모두 출력(없으면 NONE), 환기 필요 여부(경고 3회 이상 또는 1300 이상 존재). O(n)

```py
n = int(input())
co2 = list(map(int, input().split()))

warning_count = 0
warning_times = []
danger_found = False

for idx in range(n):
    value = co2[idx]
    if value >= 1000:
        warning_count += 1
        minutes = 13 * 60 + idx * 5
        warning_times.append(f"{minutes // 60:02d}:{minutes % 60:02d}")
    if value >= 1300:
        danger_found = True

need_ventilation = warning_count >= 3 or danger_found

if warning_times:
    print(" ".join(warning_times))
else:
    print("NONE")
print(need_ventilation)
```
