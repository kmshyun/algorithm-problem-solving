# 알고리즘 문제 풀이 (Algorithm Problem Solving)

"프로그래밍과 문제해결" 수업과 백준(BOJ)·Codeup·프로그래머스 등에서 푼 알고리즘 문제 풀이 코드와, 단원별 개념 정리를 모은 저장소입니다.

## 📂 구성

### `code/` — 실제 푼 코드 (Python)

| 폴더 | 내용 |
|------|------|
| `1차시` ~ `9차시` | 수업 차시별 실습 코드 |
| `수업 복습/` | 스택큐덱 · 재귀 · DFS · 백트래킹 복습 |
| `우준/` | 백준(BOJ) 문제 풀이 (문제 번호별) |
| `Codeup/` | Codeup 문제 풀이 |
| `기타 연습/`, `클로드와 놀기/` | 자유 연습 |
| `수행평가 연습/` | 수행평가 대비 |

### `notes/` — 단원별 개념 정리 & 풀이 (Notion에서 가져옴)

| 폴더 | 내용 |
|------|------|
| `단원별정리/` | 1. 프로그램 설계와 명세 ~ 8. 가중치 그래프 & Dijkstra |
| `OJ정답모음/` | 단원별 OJ 문제 정답 코드 정리 |
| `공부Tip/` | 코딩 팁, 손코딩 팁, 파이썬 세팅 |
| `수행평가/` | 수행평가 연습·실전 문제 |
| `기출문제풀이/` | 지필 기출 풀이 |

## 📚 다루는 주제

프로그램 설계/명세 · 해싱(set/dict) · 스택·큐·덱 · 누적합/투포인터/슬라이딩윈도우 · 재귀 & 백트래킹 · 그래프 & DFS · BFS · 다익스트라

---

> 개념 정리는 수업 노트를 바탕으로 정리한 것으로, 일부 설명/표/그림은 원본 Notion 페이지에 더 자세히 있습니다.
